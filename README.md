# Daily Learning Workspace

Stateful AI-powered learning. One lesson per day, built to my current level.

## Topics

- [Rubik's Cube](./rubiks-cube/) — Solve a 3×3 Rubik's Cube from scratch

## How it works

A daily cron job reads my learning state, figures out my zone of proximal development,
generates one lesson, and pushes it here. Lessons are served via GitHub Pages.
