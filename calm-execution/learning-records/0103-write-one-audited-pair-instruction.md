## What was taught

- Use this step only after two covered attempts have passed the enactment audit and been classified cue-first.
- Turn mixed, workable, or incomplete labels into one retain-and-gather instruction for two ordinary attempts.
- When the same readable `cue` or `start-side` label appears twice, use only one already-specified matching bounded test.
- Name one move, the existing observable cue, the exact two-minute action, and the two-attempt boundary.

## Key insight

A classified, audit-passed pair supports one checkable next step—not a redesign: **retain and gather, or use one existing matching test.**

## Zone of proximal development notes

The learner can audit whether a concrete two-attempt instruction was enacted and classify an audit-passed pair cue-first. This lesson adds only the translation from that pair to one enactment-ready sentence. Preserve the observable cue, exact two-minute action, two-attempt boundary, one-variable limit, and no-penalty stance. Do not add a duration goal, output goal, reminder, second test, catch-up work, or character explanation.

## What comes next

Audit the exact Lesson 103 instruction against both covered ordinary attempts. Label each `followed`, `not followed`, or `unclear`; if either is not `followed`, repeat the exact instruction unchanged for two ordinary attempts before interpreting cue or start outcomes.
