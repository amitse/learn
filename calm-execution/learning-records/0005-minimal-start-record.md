# Learning Record 0005 — Minimal Start Record

## Date

2026-07-25

## Lesson

0005 — Make a Minimal Start Record

## What was taught

- The learner records an attempt immediately after it in one line: date, cue yes/no, setup yes/no, and started yes/no.
- The record distinguishes observable links in the existing ritual without tracking hours, output, mood, or a streak.
- An optional note names only the earliest break and one test for tomorrow.
- The learner places the record beside the prepared first object so completing it adds minimal friction.

## Key insight

The record is evidence for the system, not a verdict on the person: **date — cue? y/n — setup? y/n — started? y/n**.

## Zone of proximal development notes

The learner has chosen one dependable cue, a prepared first step, and a neutral review, but has not yet established consistency. The next practice must preserve a single daily attempt and a low-burden record. Do not introduce streaks, points, time tracking, catch-up work, or output goals.

## What comes next

Lesson 0006 should teach a simple end-of-week pattern scan: use several one-line records to identify one repeated earliest break and choose one small experiment, without judging the total number of starts.
