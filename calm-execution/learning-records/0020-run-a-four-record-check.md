# Learning Record 0020 — Run a Four-Record Check

## Date
2026-08-09

## Lesson
0020 — Run a Four-Record Check

## What was taught

- The learner reads four carry-forward records using only two observable facts: `cue occurred?` and `two-minute action started?`.
- Four records where both facts are yes support retaining the same cue, action, and frequency for two more ordinary attempts.
- A missed cue identifies the cue as the earliest clear break; an occurring cue with a missed start directs one test to setup or the opening action.
- An unclear or incomplete set of records supports restraint: retain the plan until it can be read, rather than adding complexity.

## Key insight

A small set of records can guide one calm decision: **when the plan remains workable, retain it; when the earliest break is clear, test one bounded link once.**

## Zone of proximal development notes

The learner has a carry-forward ritual and a two-attempt maintenance rule, but the actual records are unknown. This lesson extends review from two to four records without raising the two-minute baseline, frequency, tracking burden, or output expectation. Do not add multiple changes, duration targets, catch-up work, penalties, or a claim that four records prove permanence.

## What comes next

After the next two ordinary attempts, teach a simple stability boundary: decide when a repeated clear break is sufficient to revise one link, and when variation is ordinary enough to retain the plan. Preserve the one-variable approach and no-penalty stance.
