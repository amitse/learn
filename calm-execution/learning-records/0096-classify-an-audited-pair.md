## Date

## Lesson
0096 — Classify an Audited Pair

## What was taught

- Only after both covered attempts are audited as `followed`, read each attempt cue-first: `cue occurred?`, then `two-minute action started?`.
- Label each attempt `cue`, `start-side`, `none`, or `unclear` from the record.
- Retain and gather records for working, mixed, or unclear pairs; consider only one already-specified matching test when the same readable `cue` or `start-side` break appears twice.

## Key insight

A pair is useful only after enactment is confirmed, and its outcome becomes legible when it is read in order: **cue first, start second.**

## Zone of proximal development notes

The learner can audit whether a bounded instruction was followed across two attempts. This lesson adds cue-first outcome classification while maintaining the existing cue, exact two-minute action, two-attempt boundary, and no-penalty stance. Do not add a new test, duration target, output target, or explanation of character.

## What comes next

Turn an audit-passed, cue-first classified pair into one exact next instruction: retain and gather, or use only one already-specified matching test; name the existing observable cue, exact two-minute action, and two-attempt boundary.
