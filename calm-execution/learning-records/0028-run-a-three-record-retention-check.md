# Learning Record 0028 — Run a Three-Record Retention Check

## Date
2026-08-17

## Lesson
0028 — Run a Three-Record Retention Check

## What was taught

- The learner reads a retained test and its next two ordinary attempts in a fixed order: `test used?`, `cue occurred?`, then `two-minute action started?`.
- A test not used in every record is incomplete evidence and directs the learner to gather two ordinary records rather than interpret the test.
- When the test is used, no repeated earliest break supports retaining it for two more ordinary attempts; clear added friction supports returning to the prior plan.
- The same earliest break in at least two readable records supports specifying exactly one matching bounded test.

## Key insight

A retained test needs a modest reading, not a verdict: **confirm it was used, read cue then start across three records, and retain, return, or gather evidence before changing anything else.**

## Zone of proximal development notes

The learner has a carry-forward ritual, a stability boundary, a test specification, and a two-record test follow-up, but actual evidence remains unknown. This lesson extends the reading window by one record without increasing duration, frequency, tracking burden, or output expectations. Preserve the two-minute baseline, chosen frequency, no-penalty stance, and one-variable approach. Do not add catch-up work, multiple changes, or a larger system.

## What comes next

After the next two ordinary attempts, teach a compact re-triage: label the earliest break across four to six readable records and either retain the current plan or write one new bounded test only when the same break appears twice.
