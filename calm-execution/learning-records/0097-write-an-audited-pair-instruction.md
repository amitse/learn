# Learning Record 0097 — Write an Audited-Pair Instruction

## Date
2026-10-25

## Lesson
0097 — Write an Audited-Pair Instruction

## What was taught

- After both attempts pass the enactment audit and are classified cue-first, write one exact next instruction.
- For a working, mixed, or unclear pair, retain the same observable cue and exact two-minute action and gather two ordinary records.
- Only when the same readable break appears twice may the instruction use one already-specified matching test; every instruction names the cue, action, and two-attempt boundary.

## Key insight

A classified pair becomes useful only when it produces a **single checkable next instruction**, rather than a redesign or a judgement.

## Zone of proximal development notes

The learner can audit a two-attempt instruction and classify an audit-passed pair cue-first. This lesson asks them to turn that result into one bounded sentence while preserving the existing cue, exact two-minute action, two-attempt boundary, and no-penalty stance. Do not add duration, output, or catch-up targets.

## What comes next

Audit the new instruction across its two covered attempts: label each `followed`, `not followed`, or `unclear`; repeat it unchanged if enactment is not yet readable.
