# Learning Record 0088 — Write an Enacted-Pair Instruction

## Date
2026-10-16

## Lesson
0088 — Write an Enacted-Pair Instruction

## What was taught

- The learner turns an enacted, cue-first classified pair into one exact instruction for the next two ordinary attempts.
- Mixed, workable, or unclear evidence produces a retain-and-gather instruction using the existing observable cue and exact two-minute action.
- Only two matching readable `cue` or `start-side` labels, with one already-specified matching test, permit that one test; every other link stays stable.
- The instruction states a two-attempt boundary so enactment can be audited before outcomes are interpreted.

## Key insight

A classified pair supports a calm next move when it becomes one checkable sentence: **one move, the same observable cue, the exact two-minute action, and two ordinary attempts.**

## Zone of proximal development notes

The learner can write, audit, and classify a cue-first two-attempt instruction. This lesson adds the narrow translation from an enacted pair to an enactment-ready next instruction while preserving the two-minute baseline, chosen frequency, no-penalty stance, and one-variable boundary. Do not add duration, catch-up work, a second test, or a character explanation.

## What comes next

Audit the two covered attempts against the exact Lesson 88 sentence. Mark each `followed`, `not followed`, or `unclear`; repeat the instruction unchanged for two ordinary attempts unless both records are `followed`.
