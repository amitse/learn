## What was taught

- Use this step only after two covered attempts passed the enactment audit and were classified cue-first.
- Turn mixed, workable, or unclear labels into one retain-and-gather instruction for two ordinary attempts.
- Only when the same readable `cue` or `start-side` label appears twice, use one already-specified matching bounded test.
- Name one move, the existing observable cue, the exact two-minute action, and the two-attempt boundary.

## Key insight

A classified pair authorizes one checkable next step—not an overhaul: **retain and gather, or run one existing matching test.**

## Zone of proximal development notes

The learner can audit whether a concrete instruction was enacted and classify an audit-passed pair cue-first. This lesson adds only the translation from that pair to one enactment-ready sentence. Preserve the observable cue, exact two-minute action, two-attempt boundary, one-variable limit, and no-penalty stance. Do not add a duration goal, output goal, reminder, second test, catch-up work, or character explanation.

## What comes next

Audit the exact Lesson 106 instruction against both covered ordinary attempts. Label each `followed`, `not followed`, or `unclear`; if either is not `followed`, repeat the exact instruction unchanged for two ordinary attempts before interpreting cue or start outcomes.
