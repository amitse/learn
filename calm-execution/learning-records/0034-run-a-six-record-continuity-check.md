# Learning Record 0034 — Run a Six-Record Continuity Check

## Date
2026-08-23

## Lesson
0034 — Run a Six-Record Continuity Check

## What was taught

- The learner reads six recent ordinary attempts in a fixed order: `test used?` (when applicable), `cue occurred?`, then `two-minute action started?`.
- An unused or unclear test, or an unclear cue/start field, makes the set incomplete; the learner keeps the instruction and gathers two ordinary records.
- Each readable record receives one earliest-break label: `none`, `cue`, or `start-side`.
- When no earliest break appears twice, the learner retains the same small plan for two ordinary attempts; a repeated earliest break supports exactly one matching bounded test.

## Key insight

A sixth record checks continuity rather than demanding a new plan: **when no earliest break repeats twice, retain the small plan for two ordinary attempts; when one does, test one matching link only.**

## Zone of proximal development notes

The learner has a carry-forward ritual, a stability boundary, test-fidelity checks, and a five-record stability check, while actual evidence remains unknown. This lesson extends the review window by one record without treating six records as proof. Preserve the two-minute baseline, chosen frequency, no-penalty stance, and one-variable approach. Do not add catch-up work, duration targets, multiple changes, or a larger tracking system.

## What comes next

After two ordinary attempts, teach a compact maintenance handoff: use the six-record reading to decide whether to retain the current instruction for a modest review interval, or write one new bounded test only when the same earliest break remains repeated.
