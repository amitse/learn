# Learning Record 0083 — Audit a Cue-First Next Instruction

## Date
2026-10-11

## Lesson
0083 — Audit a Cue-First Next Instruction

## What was taught

- The learner compares the exact Lesson 82 sentence with each of its two covered ordinary attempts.
- Each attempt receives one enactment label: `followed`, `not followed`, or `unclear`.
- If either label is `not followed` or `unclear`, the same instruction is repeated for two ordinary attempts before outcomes are read. If both are `followed`, the pair is ready for cue-first outcome classification.

## Key insight

A pair can inform a plan only after it is clear that the same written plan was enacted in both attempts.

## Zone of proximal development notes

The learner already writes a cue-first instruction with a stable cue, exact two-minute action, and two-attempt boundary. This lesson adds a narrow audit gate: enactment first, outcomes later. It preserves the no-catch-up, no-punishment stance and avoids adding a second change while evidence is unclear.

## What comes next

When both covered attempts are `followed`, classify the pair in order: `cue occurred?`, then `two-minute action started?`, using `cue`, `start-side`, `none`, or `unclear`. When the audit does not pass, repeat the instruction unchanged first.
