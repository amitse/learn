# Learning Record 0032 — Run a Four-Record Test Retention Check

## Date
2026-08-21

## Lesson
0032 — Run a Four-Record Test Retention Check

## What was taught

- The learner reads four recent attempts intended to use the same bounded test in a fixed order: `test used?`, `cue occurred?`, then `two-minute action started?`.
- An unused or unclear test is incomplete evidence; the learner keeps the instruction unchanged and gathers two ordinary records.
- Used, readable records receive one earliest-break label: `none`, `cue`, or `start-side`.
- No repeated earliest break supports retaining the test for two ordinary attempts; clear repeated cue or start-side breaks support exactly one matching bounded test, with all other links stable.

## Key insight

Four records can support restraint: **confirm the same test was used, then retain it unless the same earliest break appears twice; make only one bounded next change.**

## Zone of proximal development notes

The learner has a carry-forward ritual, stability boundary, test specification, fidelity check, and two-record comparison, while actual evidence remains unknown. This lesson extends the review window without treating four records as proof. Preserve the two-minute baseline, chosen frequency, no-penalty stance, and one-variable approach. Do not add catch-up work, duration targets, multiple changes, or a larger tracking system.

## What comes next

After two ordinary attempts, teach a compact five- or six-record review that distinguishes stable retention from a repeated earliest break, while keeping the same one-variable and no-penalty boundary.
