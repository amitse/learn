## Date
2026-10-27

## Lesson
0099 — Classify an Enacted Pair

## What was taught

- Only after both covered attempts are audited as `followed`, read each attempt in a fixed order: `cue occurred?`, then `exact two-minute action started?`.
- Label each attempt `cue` when the cue did not occur, `start-side` when the cue occurred but the action did not start, `none` when both occurred, or `unclear` when either fact is missing.
- Retain the current plan and gather another ordinary readable pair for mixed, working, or incomplete evidence.
- Only two matching readable `cue` or `start-side` labels can support one already-specified matching bounded test; the lesson does not invent a new test.

## Key insight

Once enactment is confirmed, a pair is read as observable facts rather than a verdict: **cue first, start second, then one neutral label per attempt.**

## Zone of proximal development notes

The learner can now write and audit a bounded two-attempt instruction. This lesson adds only cue-first outcome classification after that audit gate. Preserve the existing observable cue, exact two-minute action, chosen frequency, one-variable boundary, and no-penalty stance. Do not add duration, output goals, catch-up work, reminders, a second test, or a character explanation.

## What comes next
