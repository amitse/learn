# Learning Record 0014 — Write One Obstacle–Response Rule

## Date

2026-08-03

## Lesson

0014 — Write One Obstacle–Response Rule

## What was taught

- The learner identifies one predictable, observable obstacle to the existing start ritual.
- The learner writes one bounded rule: `If [obstacle], then [same small response].`
- The response preserves the primary cue, two-minute action, finish line, and one fallback rather than creating a second daily routine.
- The record gains three optional inspection fields: `obstacle occurred?`, `response used?`, and `started?`.

## Key insight

A predictable disruption need not trigger a fresh negotiation: **name one observable obstacle in advance and pair it with one calm response that protects the existing start.**

## Zone of proximal development notes

The learner has a complete, bounded ritual and a one-variable experiment process, but consistency remains unproven. This lesson adds one conditional response only for a known obstacle. Do not add a catalogue of contingencies, extra reminders, longer sessions, catch-up work, or penalties. If the obstacle never occurs, the ordinary primary-cue ritual remains the practice.

## What comes next

Lesson 0015 should teach a brief record-reading practice for the obstacle–response rule: distinguish whether the obstacle occurred, whether the response was used, and where the earliest break remained before deciding on one next adjustment.
