# Learning Record 0007 — Use One Fallback Cue

## Date

2026-07-27

## Lesson

0007 — Use One Fallback Cue

## What was taught

- The primary cue remains the normal start plan; a fallback is used only after that cue is missed.
- The learner chooses one observable later event and retains the same prepared two-minute opening action.
- The recovery rule is bounded: one fallback, no extra reminders, catch-up session, or penalty.
- A disrupted-day record can distinguish `primary missed?`, `fallback used?`, and `started?`.

## Key insight

A disruption does not require an all-day negotiation: **if the primary cue is missed, use one pre-chosen later event for the same two-minute action, then return to the primary cue tomorrow.**

## Zone of proximal development notes

The learner has a primary cue, prepared opening action, minimal record, and a way to inspect breaks, but consistency is not established. This adds only one bounded recovery option. It must not become multiple alarms, an alternative daily routine, catch-up work, or an output target.

## What comes next

Lesson 0008 should teach how to protect the start from an immediate digital detour: make one specific distraction unavailable for the two-minute opening action, while preserving the same cue and bounded system.
