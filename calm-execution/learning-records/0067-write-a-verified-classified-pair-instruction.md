# Learning Record 0067 — Write a Verified Classified-Pair Instruction

## Date
2026-09-25

## Lesson
0067 — Write a Verified Classified-Pair Instruction

## What was taught

- The learner turns a verified, classified two-attempt pair into one exact instruction for the next two ordinary attempts.
- When the same readable `cue` or `start-side` break appears twice, the instruction may use one already-specified matching test.
- For `none`, mixed, or `unclear` labels—or when no matching test already exists—the learner retains the existing plan and gathers two readable records.
- Every instruction names the existing observable cue and exact two-minute action, with no catch-up work or added changes.

## Key insight

A small pair supports a small instruction: **retain and gather unless the same readable break appears twice and an existing matching test is ready.**

## Zone of proximal development notes

The learner can audit enactment and classify a verified pair. This lesson turns that reading into an enactable next move without escalating the system: one instruction, stable cue, exact two-minute action, and a two-attempt boundary. Do not add duration, new tests, multiple changes, or more tracking.

## What comes next

Audit the new verified classified-pair instruction across its two covered attempts. Mark each `followed`, `not followed`, or `unclear`; repeat the exact instruction for two ordinary attempts unless both records are `followed`.
