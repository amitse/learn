# Learning Record 0112 — Write One Evidence-Bound Next Instruction

## Date
2026-11-09

## Lesson
0112 — Write One Evidence-Bound Next Instruction

## What was taught

- After both covered attempts pass the enactment audit and have been classified cue-first, write one next instruction rather than redesigning the ritual.
- For a mixed, working, or unclear pair, retain the existing observable cue and exact two-minute action and gather two ordinary records.
- Only when the same readable `cue` or `start-side` break appears twice—and one matching bounded test was already specified—write that single test into the instruction.
- Make the instruction checkable by naming the cue, the exact action, and the two-attempt boundary.

## Key insight

The next action follows the evidence: **one pair, one supported move, two ordinary attempts.** Mixed evidence calls for records, not a rescue plan.

## Zone of proximal development notes

The learner can audit whether a concrete instruction was enacted and classify an audit-passed pair cue-first. This lesson adds only the translation from that classification to one exact sentence. Preserve the observable cue, exact two-minute action, two-attempt boundary, one-variable limit, and no-penalty stance. Do not add a duration target, output target, reminder, second test, catch-up work, or character explanation.

## What comes next

Audit the two covered attempts against this exact evidence-bound instruction. If either is `not followed` or `unclear`, repeat it unchanged for two ordinary attempts; only audit-passed attempts may be classified.
