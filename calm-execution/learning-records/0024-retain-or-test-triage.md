# Learning Record 0024 — Run a Retain-or-Test Triage

## Date
2026-08-13

## Lesson
0024 — Run a Retain-or-Test Triage

## What was taught

- The learner reads a small set of four to six ordinary carry-forward records in earliest-break order: cue, then two-minute start.
- Each readable record is labelled `none`, `cue`, or `start-side`.
- Working, mixed, or incomplete records direct the learner to retain the current plan and gather ordinary evidence.
- Only the same earliest break in at least two readable records supports exactly one matching bounded test: a cue test, or one setup *or* opening-action test.

## Key insight

A small review can make restraint explicit: **no repeated earliest break means retain the plan; one repeated break means test one matching link once.**

## Zone of proximal development notes

The learner has a carry-forward ritual, a stability boundary, and a three-record consolidation decision, but actual records remain unknown. This lesson broadens the review window slightly without treating a pattern as proof. Preserve the two-minute baseline, chosen frequency, no-penalty stance, and one-variable approach. Do not add duration, targets, catch-up work, multiple changes, or tracking burden.

## What comes next

After the next ordinary attempt, teach how to write a one-sentence test specification only when the triage supports it: name the link, the exact bounded change, and the stable links. If triage supports retention, practice keeping the plan unchanged without inventing a test.
