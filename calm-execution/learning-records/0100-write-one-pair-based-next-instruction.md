# Learning Record 0100 — Write One Pair-Based Next Instruction

## Date
2026-10-28

## Lesson
0100 — Write One Pair-Based Next Instruction

## What was taught

- Use this step only after two covered attempts were audited as `followed` and classified cue-first.
- Turn mixed, working, or unclear labels into one retain-and-gather instruction for two ordinary attempts.
- When the same readable `cue` or `start-side` label appears twice, use only one already-specified matching bounded test.
- Name the existing observable cue, exact two-minute action, one move, and the two-attempt boundary in the instruction.

## Key insight

A classified pair does not demand a redesign. It supports a single, checkable next instruction: **retain and gather**, or **use one existing matching test**.

## Zone of proximal development notes

The learner can audit enactment and classify an audit-passed pair. This lesson adds only the translation from that pair to a concrete two-attempt instruction. Preserve the existing cue, exact two-minute action, chosen frequency, one-variable boundary, and no-penalty stance. Do not add a duration goal, output goal, reminder, second test, catch-up work, or character explanation.

## What comes next

Audit whether the exact pair-based instruction was followed in both covered attempts before interpreting cue and start outcomes.
