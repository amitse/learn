# Learning Record 0033 — Run a Five-Record Stability Check

## Date
2026-08-22

## Lesson
0033 — Run a Five-Record Stability Check

## What was taught

- The learner reads five recent ordinary attempts in a fixed order: `test used?` (when applicable), `cue occurred?`, then `two-minute action started?`.
- An unused or unclear test, or an unclear cue/start field, makes the set incomplete; the learner keeps the current instruction and gathers two ordinary records.
- Each readable record receives one earliest-break label: `none`, `cue`, or `start-side`.
- When no earliest break appears twice, the learner retains the same cue, two-minute action, and chosen frequency for two ordinary attempts; a repeated earliest break supports exactly one matching bounded test.

## Key insight

Five readable records can support calm maintenance: **when no earliest break repeats twice, retain the small plan for two ordinary attempts; when one does, test one matching link only.**

## Zone of proximal development notes

The learner has a carry-forward ritual, a stability boundary, test fidelity checks, and four-record retention practice, while the actual evidence remains unknown. This lesson slightly extends the review window and distinguishes practical stability from proof. Preserve the two-minute baseline, chosen frequency, no-penalty stance, and one-variable approach. Do not add catch-up work, duration targets, multiple changes, or a larger tracking system.

## What comes next

After two ordinary attempts, teach a compact six-record review that compares the five-record decision with the two newer records: retain stable evidence, or specify one bounded test only when the same earliest break remains repeated.
