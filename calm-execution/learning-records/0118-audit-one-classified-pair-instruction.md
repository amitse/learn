# Learning Record 0118 — Audit One Classified-Pair Instruction

## Date
2026-11-15

## Lesson
0118 — Audit One Classified-Pair Instruction

## What was taught

- Compare the exact decision-ready instruction with each of its two covered ordinary attempts before interpreting cue or start outcomes.
- Label each attempt `followed`, `not followed`, or `unclear` by checking the named cue, exact two-minute action, and any named test.
- Only when both attempts are `followed` is the pair ready for cue-first outcome classification.
- When either label is `not followed` or `unclear`, repeat the exact instruction for two ordinary attempts; do not add a new change or consequence.

## Key insight

**An outcome is interpretable only after the instruction itself is readable.** An incomplete audit calls for a calm repeat, not a new theory about motivation.

## Zone of proximal development notes

The learner can classify an audit-passed pair and write one decision-ready two-attempt instruction. This lesson adds only the enactment audit of that written instruction. Preserve the observable cue, exact two-minute action, two-attempt boundary, one-variable limit, and no-penalty stance. Do not add a duration target, output target, reminder, catch-up work, second test, or character explanation.

## What comes next

When both covered attempts are `followed`, classify each cue-first as `cue`, `start-side`, `none`, or `unclear`. Retain and gather records unless the same readable break appears twice and has one already-specified matching bounded test.
