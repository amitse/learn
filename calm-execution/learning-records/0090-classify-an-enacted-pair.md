## Lesson
0090 — Classify an Enacted Pair

## What was taught

- After two covered attempts are audited as `followed`, the learner reads each attempt in the same order: `cue occurred?`, then `two-minute action started?`.
- A readable attempt is labelled `cue` when the cue did not occur, `start-side` when the cue occurred but the action did not start, and `none` when both occurred; missing facts are `unclear`.
- Only the same readable `cue` or `start-side` label twice permits one already-specified matching test. Mixed, working, or unclear evidence means retaining the plan and gathering two ordinary records.

## Key insight

An enacted pair becomes useful evidence only when read in sequence: **cue first, start second; classify facts before choosing a next move.**
