# Learning Record 0094 — Write a Pair-Based Next Instruction

## Date
2026-10-22

## Lesson
0094 — Write a Pair-Based Next Instruction

## What was taught

- Turn the two labels from an audit-passed pair into one next instruction.
- Include one move, the observable cue, the exact two-minute action, and a two-attempt boundary.
- Retain and gather for mixed, working, or unclear evidence; use only one already-specified matching test when the same readable `cue` or `start-side` break appears twice.

## Key insight

A classified pair does not call for a redesign. It calls for **one checkable sentence** that protects the existing cue and two-minute action while the next two ordinary attempts supply evidence.

## Zone of proximal development notes

The learner can audit enactment and classify an audit-passed pair cue-first. This lesson asks them to convert that classification into a bounded instruction without adding urgency, output targets, catch-up work, duration, a second test, or a character judgment.

## What comes next

Audit whether the exact pair-based instruction was followed in each of its two covered attempts before interpreting cue or start outcomes.
