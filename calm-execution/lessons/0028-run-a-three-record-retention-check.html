Calm Execution · Lesson 28 · 10 minutes

Run a three-record retention check

A retained test does not need a grand verdict. Read three ordinary attempts, then make the smallest justified decision.

The one skill

Classify a retained test across three readable records without adding a new change.

First confirm the named test was used. Then read cue → two-minute start. Change one link only if the same earliest break appears in at least two records.

Why this is a calm experiment

This is a practical way to keep your system inspectable, not a claim that three records prove a cause. Repetition in a stable context is relevant to habit formation, but this tiny check is only evidence for the next modest decision—not a diagnosis or a performance grade. Gardner, Lally & Wardle (2012)

Your 10-minute exercise

  1. Put the retained-test record beside the next two ordinary records.
  2. For each, mark: test used? then cue occurred? then two-minute action started?
  3. Choose one result: retain if the test was used and no same break appears twice; return only if it clearly added friction; otherwise gather two more ordinary records.
  4. Make one ordinary next attempt. No catch-up and no upgrade.

If any record is missing or the test was not used, it is incomplete evidence—not a failed test.

Quick decision check

Write the next line

“For my next ordinary attempt, I will [retain / return / gather evidence], while keeping [cue and two-minute action] unchanged.”

Ask your teacher if you want help reading an ambiguous record. The aim is a calm, usable next attempt.
