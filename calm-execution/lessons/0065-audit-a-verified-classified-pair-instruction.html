Audit a verified classified-pair instruction

Before reading what happened, check whether the exact instruction from Lesson 64 was actually used in both attempts.

Instruction first → two enactment labels → outcomes only when both say followed.

One skill

Compare the sentence you wrote with each of its two covered attempts. Give each attempt one label:

  • followed: the stated next move, cue, and exact two-minute action were used.
  • not followed: a named part was not used.
  • unclear: the record cannot show whether it was used.

This is a practical audit, not a judgment. Do not reconstruct a missing detail. If either label is not followed or unclear, repeat the exact instruction for two ordinary attempts—no new change, and no cue/start interpretation yet.

The decision rule

  1. Put the exact prior instruction where you can see it.
  2. Read attempt one and attempt two against that sentence.
  3. Label each one followed, not followed, or unclear.
  4. If both are followed, the pair is ready for the next lesson’s cue-then-start reading. Otherwise, repeat the instruction unchanged for two ordinary attempts.

“Repeat” means the same small plan—not catch-up work, a longer session, or extra reminders.
