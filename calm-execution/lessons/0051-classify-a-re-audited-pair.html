Calm Execution · Lesson 51

Classify a re-audited pair

Once both attempts followed the instruction, read each outcome in the same small order: cue first, start second.

One skill: give each readable attempt one label

Use this only after Lesson 50’s audit says both attempts were followed. For each record, read cue occurred?, then two-minute action started?.

cue = the cue did not occur. start-side = the cue occurred but the action did not start. none = cue and action both happened. unclear = the record cannot tell.

Two matching readable cue or start-side labels may support one already-specified matching test. Any other pair—working, mixed, or unclear—means retain the current instruction and gather two ordinary records. This is a practical decision rule, not a diagnosis or a claim that two records prove a cause.

For context on why stable contexts can matter for cue-triggered habits, see Gardner, Lally & Wardle (2012). This lesson’s classification rule is a deliberately modest practice tool.

10-minute applied exercise

  1. Confirm both covered attempts were labelled followed in the instruction audit.
  2. Read attempt 1: cue first, then two-minute start. Choose one label below.
  3. Repeat for attempt 2. Do not fill gaps from memory.
  4. Use the feedback to write one next move: retain/gather two records, or use one already-specified matching test.

Pair classifier

The aim remains one calm, pre-chosen start—not a longer session, catch-up work, or a verdict about you. Ask your teacher if a record is hard to label.
