Calm Execution · Lesson 20

Run a four-record check

After two ordinary maintenance attempts, use four small records to choose restraint or one bounded refinement—not a bigger system.

One skill

Read four carry-forward records in order: cue, then start. Retain the plan if it remains workable; otherwise name the earliest clear break and test one link once.

This is a practical reading exercise, not a score or a diagnosis. Four records cannot prove a permanent habit. They can help you make the next attempt less speculative.

10–15 minutes

Applied exercise: make one four-record decision

  1. Place your four most recent carry-forward records in front of you.
  2. For each one, mark only cue occurred? and two-minute action started?
  3. If cue and start are both yes in all four, write: “Keep my current cue, action, and frequency for the next two ordinary attempts.”
  4. If a cue is no, write one small cue test. If a cue is yes but start is no, write one small setup or opening-action test. Change nothing else.
  5. Make the next ordinary attempt. Do not add catch-up work, a longer session, or a penalty.
Example: Four records show the cue occurred each time, but one start was missed. Decision: “For one attempt, put the outline beside my keyboard before lunch. Keep the cue and two-minute action the same.”

Check your decision

Immediate feedback only; nothing is stored.

Tomorrow’s rule

Four workable records support keeping the plan small. An earliest clear break supports one small test. An unclear record supports no new complexity.

Ask your teacher to help read a confusing record. The aim remains a calm, intentional beginning—not urgency, guilt, punishment, or a bigger system.
