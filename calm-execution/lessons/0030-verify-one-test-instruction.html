Calm Execution · Lesson 30

Verify one test instruction

Before you interpret a test, check that today’s action actually matched the change you wrote.

One skill: separate “not used” from “didn’t work”

This is a practical record-reading exercise, not a diagnosis. A test has evidence only when its exact named change happened. Cue-based practice is relevant here because habits can be linked to stable contextual cues; the useful question for your own system is still concrete: what did you actually do today? Source: Gardner, Lally & Wardle (2012).

Read in order: (1) Did I use the exact test? (2) Did the cue occur? (3) Did the two-minute action start? If step 1 is no or unclear, write incomplete—not “the test failed.”

10-minute applied exercise

  1. Open your current one-sentence test specification and one recent attempt record.
  2. Underline the exact changed behavior in the specification. Examples: “put cue card beside mug” or “open the document before the cue.”
  3. Write one line: test used? yes/no/unclear · cue? yes/no · started? yes/no.
  4. Choose one next ordinary attempt: if the test was used, keep it stable while you gather evidence; if not, use the same test once without adding another change.

Instruction checker

Paste your test instruction and record what happened. You will get immediate feedback about whether it is interpretable.

Carry forward: a clear test record may support calm retention; an unused or unclear test supports another ordinary attempt with the same instruction. Neither calls for a redesign, a longer session, or punishment.

Ask your teacher if you want help making a current test instruction more observable.
