Review a Miss Neutrally

Turn one “didn’t start” into one small adjustment—not a character judgment.

Win for today: make a reusable, one-minute review for any missed start.

A miss is a fork, not a verdict

You already have three inspectable parts: a cue, a one-barrier setup, and a two-minute first action. When a start does not happen, do not ask “What is wrong with me?” Ask which part needs redesigning.

Missed start → name the earliest break → make one adjustment → test tomorrow

This is a practical experiment, not a diagnosis or a promise that any single change will work. Repeating behaviour in a stable context can support cue-driven habits; this log gives you a way to see whether your particular cue and setup are becoming usable.

Source: Gardner, Lally & Wardle (2012), “Making health habitual” (verified 2026-07-23).

Use only three questions

  1. Did the cue happen or get noticed? If not, make it more visible or attach it to a more reliable event.
  2. Was the one-barrier setup done? If not, shrink it or move it earlier.
  3. Was the two-minute action clear and available? If not, make its first physical move smaller or more specific.

Stop after the earliest break. One change is enough for a fair test tomorrow.

Make a neutral review card

Quick check

A cue happened, but the file was not ready. Which review keeps the system calm and specific?

10-minute field exercise

  1. Minute 0–3: Pick one real missed start from this week, or use a plausible one. Complete the review card.
  2. Minute 3–7: Do the single adjustment now if you can—place the note, open the file, or choose a clearer cue.
  3. Minute 7–10: Add one line to the start log: date — missed because: cue/setup/action — tomorrow’s one change: ___.

Tomorrow, run the usual two-minute start. Record only whether it started. You are testing a design, not earning a verdict.
