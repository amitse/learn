Calm Execution · Lesson 75 · 10 minutes

Classify an audited next instruction

Once two attempts really followed the written plan, locate the earliest observable break—without turning either result into a verdict.

For each verified attempt: read cue occurred? first, then two-minute action started?. Label it cue, start-side, none, or unclear.

The one skill

  1. Use only the two attempts that passed the Lesson 74 audit as followed.
  2. For each, label cue if the cue did not occur; label start-side if it occurred but the action did not start; label none if both occurred; otherwise use unclear.
  3. Only two matching readable breaks point to one already-specified matching test.
  4. For mixed, working, or incomplete evidence, retain the plan and gather two ordinary records. Do not redesign or catch up.

This is a practical reading rule for your own small experiment. It keeps a miss as system data, not a character judgment.

Practice: classify the audited pair

Use the two attempts you labelled followed in Lesson 74. This takes 5–10 minutes.

Close the loop

Copy the two labels and the next move into your one-line record. If a test is supported, use only the matching test you already specified. Otherwise keep the cue and exact two-minute action unchanged for two ordinary attempts.

Questions or a difficult real record? Ask your teacher agent and include the audit result plus both labels.

Optional background on habit formation: Gardner, Lally & Wardle, “Making health habitual” (2013). The decision rule above is a practical course experiment, not a diagnostic tool.
