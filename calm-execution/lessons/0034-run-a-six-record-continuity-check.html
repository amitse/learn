Calm Execution · Lesson 34

Run a six-record continuity check

Compare a five-record decision with the next ordinary record—without turning variation into a verdict.

The one skill

Read six recent ordinary attempts in order: test used? (when relevant), cue occurred?, then two-minute action started?. Label each readable attempt none, cue, or start-side. The sixth record is not a redo; it checks whether the same decision still fits the fuller set.

Six readable records → no earliest break repeated twice → retain the same small plan for two ordinary attempts.

This is a practical decision rule, not a scientific threshold. The course’s cue-and-small-action practice is informed by Gardner, Lally & Wardle’s review, which describes habits as actions triggered by contextual cues: verified source.

Your 12-minute exercise

  1. Place your five records from the last review beside the next ordinary record. Use only attempts made with the current written plan.
  2. If a bounded test is current, first check whether its exact change was used in every record. If any answer is no or unclear, stop: keep the instruction and gather two ordinary records.
  3. For every readable record, label the earliest break: cue if the cue did not occur; start-side if the cue occurred but the two-minute action did not start; otherwise none.
  4. Use the checker. Copy its one instruction beside your log, then make one ordinary next attempt—no catch-up work and no extra change.

Interactive continuity checker

Use “not applicable” if there is no current bounded test. “Unclear” means the record cannot answer that field.

Keep the result small

Retention means the same cue, two-minute action, chosen frequency, and any current test. A repeated break permits exactly one matching bounded test: change the cue, or change one start-side link (setup or opening action). It does not require more effort.

Ask your teacher a follow-up question if a label is ambiguous. The aim is a readable next attempt, not a perfect explanation.
