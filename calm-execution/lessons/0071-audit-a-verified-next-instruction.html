Audit a verified next instruction

Before interpreting results, check whether the exact Lesson 70 instruction was actually used on its two covered attempts.

Instruction first → enactment check → only then read outcomes.

One skill

Compare the same written instruction with each covered attempt. Give each one a plain label: followed, not followed, or unclear. This is a practical evidence check, not a judgment about effort.

  1. Read your Lesson 70 sentence exactly as written.
  2. For attempt one and attempt two, ask only: did I use that sentence’s move, cue, and exact two-minute action?
  3. If either label is not followed or unclear, repeat the same sentence for two ordinary attempts. Do not interpret cue or start outcomes yet.
  4. Only if both labels are followed, keep the records ready for the next lesson’s cue-then-start reading.

Take forward

Do not repair an outcome with a new plan before checking enactment. One exact sentence, two ordinary attempts, then a factual audit keeps the system small and non-punitive. Ask me a follow-up question if a label is hard to assign.
