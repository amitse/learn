Calm Execution · Lesson 24

Run a retain-or-test triage

Use a small set of ordinary records to choose between restraint and exactly one new bounded test.

One skill

Sort the records by their earliest break. Retain the plan unless the same readable break appears at least twice.

This is a practical decision rule for your own records, not a diagnosis or proof of why a start happened. It fits the course’s cue-based approach; habit research discusses how repeated behaviour in stable contexts can become more cue-driven. Gardner, Lally & Wardle (2012).

10–15 minutes

Applied exercise: make a triage slip

  1. Gather the latest four to six ordinary records. Do not add a new tracking field.
  2. For each readable record, read: cue occurred?, then two-minute action started?. Label it none, cue, or start-side.
  3. Make one decision: retain if records are working, mixed, or incomplete. Name one bounded test only if cue or start-side is the same earliest break in at least two records.
  4. Write the next ordinary attempt. A retained plan is complete; it does not need a reward, catch-up session, or upgrade.
Example: none, cue, none, start-side. No break repeats, so retain the current plan and collect ordinary evidence. Not: change both the cue and setup to cover every possibility.

Check your triage

Immediate feedback only; nothing is stored.

Tomorrow’s rule

No repeated earliest break? Keep the plan. One repeated break? Test one matching link once.

Ask your teacher to help classify a record that is hard to read. The aim is still one calm, intentional beginning—not urgency, guilt, punishment, or a larger system.
