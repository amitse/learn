Calm Execution · Lesson 32

Run a four-record test retention check

Decide whether to keep one bounded test—without turning four attempts into a verdict.

The one skill

Read four recent attempts with the same test instruction. First check whether that instruction was used. Then read the cue, then the two-minute start. Make one small decision only.

Keep the test unless it clearly added friction or the same earliest break appears in at least two readable records.

Why use a stable cue and repeated small action at all? This course’s practical experiment is informed by Gardner, Lally & Wardle’s review of cue-linked repetition and habit formation—not by a promise that four records prove a cause. Read the verified source.

Your 8–12 minute exercise

  1. Find four recent ordinary attempts that were meant to use the same written test. If you have fewer than four, stop here: keep the instruction unchanged and collect ordinary records.
  2. For each record, mark test used?, then cue occurred?, then two-minute action started?.
  3. Call a used record cue if the cue did not occur; call it start-side if the cue occurred but the start did not; otherwise call it none.
  4. Use the checker below. Apply its one next instruction on an ordinary attempt—no catch-up and no additional change.
