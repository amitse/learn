Calm Execution · Lesson 96 · 10 minutes

Classify an audited pair

When both attempts followed the same instruction, read the pair in one order: cue first, then the two-minute start.

The one skill

Use your Lesson 95 audit only when both attempts were followed. For each attempt, ask:

  1. Did the observable cue occur? If no, label it cue.
  2. If yes, did the exact two-minute action start? If no, label it start-side.
  3. If both happened, label it none. If the record cannot answer in that order, label it unclear.

Retain and gather records unless the same readable break appears twice and you already have one matching test specified. Do not invent a new test from one pair.

A practical experiment

This is a deliberately narrow reading rule, not a verdict about motivation or character. Repeating a response in a stable context is one way habits can become more cue-linked; this exercise simply keeps your evidence readable before you change the system. Gardner, Lally & Wardle (2012).

Applied exercise — classify your audited pair

Spend 5–10 minutes with the two attempts that passed your Lesson 95 audit. For each one, read cue first and start second. Choose the label the record supports.

Instant check

Both attempts followed the instruction. In A, the cue happened but the two-minute action did not start. In B, the cue did not happen. How should you label the pair?

Ask your teacher if a cue or start record is hard to classify. A neutral unclear label is useful data; no urgency, guilt, or catch-up work is required.
