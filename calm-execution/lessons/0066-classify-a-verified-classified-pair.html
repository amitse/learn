Classify a verified classified pair

When both attempts followed the instruction, read each record in the same small order: cue first, then start.

Verified enactment → cue → start → one label per attempt.

One skill

Classify two followed attempts without filling gaps from memory. This is a practical reading rule for your own records—not a verdict about you.

  • cue: the cue did not occur or is recorded as no.
  • start-side: the cue occurred, but the two-minute action did not start.
  • none: the cue occurred and the two-minute action started.
  • unclear: either needed fact is missing.

Only a pair with the same readable cue or start-side label twice can point to one already-specified matching test. Every other pair means: retain the plan and gather two ordinary readable attempts.

Background: the course’s cue-based practice draws on the distinction between repeated behaviour in a stable context and cue-driven habit described by Gardner, Lally & Wardle (2012). This exercise does not claim to diagnose why an individual attempt went as it did.

The reading order

  1. Confirm both covered attempts were labelled followed in Lesson 65.
  2. For attempt one, read cue occurred?. Only then read two-minute action started?.
  3. Give it one label. Repeat for attempt two.
  4. Retain and gather unless both readable labels are the same break and you already have one matching test written down.

Do not create a new test here, extend the session, or catch up. A missing fact stays unclear.
