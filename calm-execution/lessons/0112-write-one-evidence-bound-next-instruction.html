Calm Execution · Lesson 112 · 10 minutes

Write one evidence-bound next instruction

Turn an audit-passed pair into one small, checkable move—without adding a rescue plan.

The one skill

Use this only after both attempts passed the enactment audit and you have classified them cue-first. Your next instruction has one of two shapes:

Mixed, working, or unclear pair → retain the plan and gather two ordinary records.
Same readable break twice + an already-specified matching test → run that one test for two ordinary attempts.

The sentence must name the existing observable cue, exact two-minute action, and two-attempt boundary. It is an experiment instruction, not a verdict about motivation. This course uses stable cues as practical background; see Gardner, Lally & Wardle (2012).

Applied exercise — write yours

Take 5–10 minutes. Copy the cue and exact action from your current record. Then select the result of your audited, classified pair.

Instant check

Your pair is none, start-side. Which instruction fits?

No urgency, catch-up work, or self-punishment is required. Next: enact this exact sentence for two ordinary attempts, then audit whether it was followed. Ask your teacher if the pair or its instruction feels ambiguous.
