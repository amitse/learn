Calm Execution · Lesson 83 · 8 minutes

Audit a cue-first next instruction

Before interpreting another pair of starts, check whether you actually used the exact instruction you wrote in Lesson 82.

Read enactment first: label each of the two covered attempts followed, not followed, or unclear.

The one skill

  1. Put your Lesson 82 sentence beside the two ordinary attempt records it covers.
  2. For each attempt, ask only: did the named move, observable cue, and exact two-minute action occur as written?
  3. Label it followed, not followed, or unclear. Do not grade the outcome yet.
  4. If either label is not followed or unclear, repeat the same sentence for two ordinary attempts. If both are followed, classify cue then start next.

This is a practical course rule: it separates “the plan was not clearly enacted” from “the enacted plan had an outcome.” It is not a diagnosis or a verdict about you.

Practice: run the audit

Allow 5–8 minutes. Use your exact Lesson 82 sentence and the two attempts it covered.

Close the loop

Copy the resulting move beside your record. No catch-up work is required. You are protecting one calm, pre-chosen start from urgency and self-punishment. Ask your teacher agent if “followed” or “unclear” is hard to call.

Background reading: Gardner, Lally & Wardle, “Making health habitual” (2012). The audit rule on this page is a practical course exercise.
