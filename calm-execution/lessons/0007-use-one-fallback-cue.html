Use One Fallback Cue

When the usual cue is genuinely missed, use one pre-chosen later event—not an all-day chase.

Win for today: write one calm recovery plan that preserves the same two-minute opening action.

A disruption needs a boundary

Your primary cue is still the plan. Some days it will not happen as expected: a meeting runs over, travel intervenes, or you simply notice too late. Rather than declaring the day lost or continually renegotiating with yourself, test one fallback cue: a later, observable event that gives the same tiny action one more clear doorway.

primary cue missed → one fallback event → same prepared two-minute action → record what happened

This is a practical experiment, not a claim that a backup will fix every disruption. Repeated behaviour in a stable context can become more cue-driven, so keep the primary ritual stable and make the fallback a limited exception rather than a collection of reminders (Gardner, Lally & Wardle, 2012; verified 2026-07-27).

The one-fallback rule

  1. Keep your existing primary cue, setup, and two-minute action unchanged.
  2. Name one later event you reliably notice, such as “after I close my laptop for lunch.” It must be an event, not “when I have time.”
  3. Use it only if the primary cue was missed. At the fallback, begin the same two-minute action or record a miss.
  4. Do not add a second fallback, catch-up block, or punishment. Tomorrow returns to the primary cue.

Build your recovery card

Use concrete events and the exact action you already designed. This tool checks that the fallback is a boundary, not a larger obligation.

Quick check

The primary cue was missed. Which response follows the one-fallback rule?

10-minute field exercise

  1. Minutes 0–2: Read your current cue and two-minute opening action from your record. Do not improve them today.
  2. Minutes 2–5: Choose one later event you normally notice. Write it in the recovery card above.
  3. Minutes 5–7: Put the card beside your existing record or prepared object. Say the rule once: Primary cue first; one fallback only if it is missed.
  4. Minutes 7–10: On the next disrupted day, test it. Record primary missed? y/n — fallback used? y/n — started? y/n, plus one neutral note if useful. On an ordinary day, use only the primary cue.

A fallback start counts as an intentional start; a missed fallback is simply data. Neither requires a late-night rescue attempt.
