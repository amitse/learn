Audit the instruction before the outcome

Check whether the exact Lesson 67 instruction was followed on its two covered attempts—before reading whether either attempt started.

Exact sentence → two enactment labels → repeat or classify. Not a verdict.

One skill

Separate was the plan used? from did the start happen?. Put the Lesson 67 sentence beside each covered record and give each attempt one label:

  • followed — the named cue, two-minute action, and any active single test match the record.
  • not followed — the record shows a different plan was used.
  • unclear — the record does not say enough to check; do not fill gaps from memory.

This is a practical evidence-reading exercise. It does not explain why an attempt went as it did.

The boundary

  1. Audit the instruction first. Do not interpret cue or start results yet.
  2. If either label is not followed or unclear, repeat the exact same instruction for two ordinary attempts.
  3. Change nothing and add no catch-up work while gathering those readable attempts.
  4. Only two followed labels make the pair ready for the existing cue-then-start classification.
