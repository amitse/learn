Look for a pattern, not a verdict

You now have a cue, a one-barrier setup, a two-minute opening action, and a minimal record. A short scan asks a narrow question: where did the ritual first break most often?

several records → earliest break → one small experiment tomorrow

This is a practical experiment. Your record is a small sample, not proof of a trait or a permanent diagnosis. Keep the existing cue–setup–start fields stable long enough to inspect them; then change only one part for one next attempt. Repeated behavior in a stable context can become more cue-driven, which is why this course keeps the ritual simple and concrete (Gardner, Lally & Wardle, 2012; verified 2026-07-26).

The earliest-break rule

  1. If the cue was not noticed, mark cue—even if setup and starting were also no.
  2. If the cue was noticed but setup was not done, mark setup.
  3. If cue and setup were yes but the two-minute action did not begin, mark action.
  4. If all three were yes, mark started. It needs no repair.

12-minute field exercise

  1. Minutes 0–3: Gather your last three to five one-line records. If you have fewer than three, use the records you have; this is only an early scan.
  2. Minutes 3–6: Enter them above and read the earliest-break result. Do not total hours, rate yourself, or create a streak.
  3. Minutes 6–9: Choose one experiment for tomorrow: cue → make event more visible; setup → prepare one object tonight; or action → shrink the first physical move.
  4. Minutes 9–12: Write the experiment beside tomorrow’s record. After tomorrow’s attempt, record cue/setup/started as usual. Keep the other parts unchanged.

If there is no clear pattern yet, that is useful data too: keep the same light record for a few more attempts. No catch-up work and no penalty are required.
