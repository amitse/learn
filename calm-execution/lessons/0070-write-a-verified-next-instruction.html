Pair result → one exact next move → two ordinary attempts.

One skill

Write a next instruction with four visible parts: the move, the existing cue, the exact two-minute action, and a two-attempt boundary. This is a practical planning experiment, not a verdict on motivation or character.

  1. If both verified-pair labels were cue or both were start-side, use only one already-specified matching test.
  2. If labels were none, mixed, or included unclear, use retain and gather.
  3. Name the same observable cue and exact two-minute action. Do not add a second change, extra duration, or catch-up work.
  4. Use the sentence for two ordinary attempts; the next lesson audits whether it was followed.
