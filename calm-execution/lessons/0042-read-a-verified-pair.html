Read a verified pair

The one skill

Lesson 41 established whether the written instruction was followed. For a verified pair, now read each attempt in the same short order: did the cue occur? If yes, did the two-minute action start?

Cue absent → cue. Cue present + no start → start-side. Both present → none.

This is a practical sorting drill, not proof of why an attempt went as it did. It simply keeps the next decision tied to the earliest readable fact. Contextual cues are a useful focus because habitual actions are understood in relation to cues associated with performance; see Gardner, Lally & Wardle, “Making health habitual”.

Your 8-minute exercise

  1. Use the two attempts that passed the Lesson 41 audit.
  2. For each, select the earliest label below. Do not infer a cue from a start, or fill a missing field from memory.
  3. Read the feedback. Copy its one next instruction beside your records.
  4. Make the next two attempts ordinary: keep the cue, two-minute action, frequency, and any active test stable. No catch-up work.

Interactive reading drill

Good enough

If either record is unclear, that is not a personal failure. Retain the current instruction and gather two readable ordinary attempts. Ask your teacher if you want help making a cue or start field observable.

The aim is one calm, checkable next instruction—not an explanation of yourself.
