Calm Execution · Lesson 90

Classify an enacted pair

Once the same instruction was followed twice, read each outcome in one fixed order: cue first, then the two-minute start.

For each readable attempt: cue absent = cue; cue present + no start = start-side; both present = none.

If either fact is missing, label it unclear. Do not turn a label into a verdict about yourself. It is only a compact description of where this attempt became unreadable or stopped.

This is a practical record-reading exercise, not a claim that two attempts establish a cause. Repetition in a stable context can support inspection of a cue and a response separately; the small classification below makes that inspection explicit. Gardner, Lally & Wardle (2012).

Your 10-minute real-world exercise

Use the two ordinary attempts that passed Lesson 89’s enactment audit. For each, answer only the two questions below. Then check the result. If the same readable break appears twice, use one already-specified matching test; otherwise retain the plan and gather two more ordinary records.

Boundary: A repeated label permits at most one matching test that you already wrote down. If no such test exists—or if the evidence is mixed, working, or unclear—keep the cue and exact two-minute action unchanged for two ordinary attempts. No catch-up work or punishment.

Next: write one exact next instruction from this classification. Ask your teacher if “cue,” “start-side,” or the matching-test boundary is unclear.
