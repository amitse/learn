Calm Execution · Lesson 92

Audit a classified next instruction

Before reading outcomes, check whether the exact instruction from Lesson 91 was actually used in both ordinary attempts.

Compare the written sentence—not your intention or the result—with each attempt.

Label each attempt followed, not followed, or unclear. Only two followed labels make the pair ready to read cue and start outcomes. Any other pair means: repeat the same instruction for two ordinary attempts.

Keeping an action tied to a stable context is a common habit-formation practice; this audit is a practical way to keep your own small experiment readable, not a test of willpower. Gardner, Lally & Wardle (2012).

Your 10-minute real-world exercise

Put the exact Lesson 91 sentence beside the two attempts it covered. For each attempt, ask only: did its cue, exact two-minute action, and stated move match the sentence? Pick one label per attempt. Then follow the feedback below.

“Unclear” is a valid label when the record does not show enough to compare. Do not reconstruct it from memory.

Boundary: this is not a cue to catch up, extend the two-minute action, or add a new test. A not-followed or unclear attempt asks for the same calm instruction again—not a verdict.

Next: if both labels are followed, classify each outcome cue-first, then start-second. Ask your teacher if it is hard to tell whether the written instruction was followed.
