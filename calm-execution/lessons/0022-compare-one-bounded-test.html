Calm Execution · Lesson 22

Compare one bounded test

After changing one link once, read the before-and-after records without turning one outcome into a verdict.

One skill

Compare the one link you tested, then choose: retain it for two ordinary attempts, return to the prior plan, or gather two more records.

This is a practical record-reading experiment, not proof that one result caused an outcome. Habit practice is often discussed in relation to repeated behaviour in stable contexts; individual records still need cautious interpretation. Gardner, Lally & Wardle (2012).

10–15 minutes

Applied exercise: make a one-test comparison

  1. Find the last change you made. It must name one link: cue, setup, or opening action.
  2. Put one readable record from before the test beside the test record. For each, read cue occurred? then two-minute action started?.
  3. Write one neutral comparison: “Before: __. Test: __. The tested link was __. Next: __.”
  4. Choose one calm next move: retain the test for two ordinary attempts if it looks workable; return to the prior plan if it clearly added friction; or gather two more records if the comparison is mixed or incomplete.
Example: Before: cue missed. Test: cue note by kettle; cue occurred and action started. The tested link was the cue. Next: retain this cue setup for two ordinary attempts. This is a reason to continue observing—not a claim that the note solved everything.

Check your next move

Immediate feedback only; nothing is stored.

Tomorrow’s rule

One comparison can guide the next small observation. It does not earn an upgrade, catch-up work, or a new system.

Ask your teacher to help read a confusing before-and-after pair. The aim remains a calm, intentional beginning—not urgency, guilt, punishment, or a bigger system.
