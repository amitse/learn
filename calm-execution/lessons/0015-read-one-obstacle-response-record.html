Calm Execution · Lesson 15

Read one obstacle–response record

Let one attempt tell you where to look next—without turning it into a verdict.

One skill

After one attempt, read three facts in order: did the obstacle occur, did I use my response, and did I start?

This is a practical record-reading experiment. It keeps the obstacle rule inspectable: an obstacle can occur without a failure; a response can be used without a start; and a missed start can still point to an earlier link.

Research on habits distinguishes cue-triggered automatic responses from behaviour that is merely frequent. Use the record here to make the next response clearer, not to assume that one rule will automatically work. Gardner, Lally & Wardle (2012).

Read the record, not the story

Obstacle: no. Keep the ordinary primary-cue ritual. There is no rescue rule to judge.

Obstacle: yes; response: no. The rule was available but not used. Review what prevented the response before changing the larger ritual.

Obstacle: yes; response: yes; start: no. The response happened, but another link still broke. Later locate the earliest break: cue, setup, or action.

Obstacle: yes; response: yes; start: yes. The rule protected one start. Keep it stable; do not expand it into more rules.

10-minute applied exercise

Observe → classify → choose one next move

  1. Copy the three facts into today’s one-line record.
  2. Choose only the next move the feedback names.
  3. Tomorrow, run one ordinary attempt; do not add a second obstacle rule.

Tomorrow’s boundary

Keep the existing primary cue, two-minute action, finish line, and one fallback. If the obstacle did not happen, no adjustment is required. If it did, change only the response rule after you can name the specific break—or deliberately make no change when the record is unclear.

Ask your teacher: “Does this record show a broken response rule, or an earlier break in my existing ritual?”
