Calm Execution · Lesson 115 · 8 minutes

Write one decision-ready instruction

Turn an audit-passed, classified pair into one small sentence you can actually follow.

The one skill

Use this only after both attempts passed the enactment audit and you gave each a cue-first label. Write one instruction for the next two ordinary attempts:

For mixed, working, or unclear labels: retain the existing cue and exact two-minute action; gather two records.
For the same readable cue or start-side label twice: use one matching bounded test only if it was already specified.

Your sentence must name the observable cue, the exact two-minute action, and the two-attempt boundary. This is a practical constraint for keeping the next attempt readable, not a verdict or a demand to do more. For background on stable-context, cue-based habits, see Gardner, Lally & Wardle (2012).

Applied exercise — write the next two attempts

Spend 5–10 minutes with your classified pair. Choose its evidence state, then write one sentence. Do not add a reminder, a duration target, catch-up work, or a second test.

Instant check

A passed pair is cue, none. Which instruction fits the evidence?

One pair, one supported move, two ordinary attempts. The point is a calm next start—not a perfect plan. Ask your teacher if the pair or test is ambiguous. Next: audit whether this exact instruction was followed.
