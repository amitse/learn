Calm Execution · Lesson 27

Follow up on a bounded test

Use two ordinary attempts to decide whether to keep one tested change—without turning a single result into a verdict.

One skill

Confirm the exact test was used twice. Then read cue → two-minute start in each record and choose restraint or one clear return.

This is a practical evidence rule, not a claim that two records prove cause. Research on habit distinguishes behaviour cued by a stable context from merely frequent behaviour; this small review keeps your cue-based plan inspectable. Gardner, Lally & Wardle (2012).

8–12 minutes

Applied exercise: make a two-record follow-up

  1. Take the two ordinary attempts after your bounded test. For each, mark test used? yes only if the exact named change happened.
  2. For each used test, read cue occurred?, then two-minute action started?.
  3. Choose one next instruction: retain the test for two more ordinary attempts if both are readable and do not show clear added friction; return to the prior plan only if the tested change clearly added friction; otherwise gather two ordinary records.
  4. Make one next ordinary attempt. Do not add another change today.
Example: “Attempt 1: test used yes, cue yes, start yes. Attempt 2: test used yes, cue yes, start no; the new setup was plainly in the way. Next: return to the prior setup; gather two ordinary records.”

Practice the follow-up decision

Immediate feedback only; nothing is stored.

Keep the scope small

Mixed evidence is permission to observe, not a cue to redesign. One unchanged ordinary attempt is still the practice.

Ask your teacher to help tell clear added friction from mixed evidence. The aim remains one calm intentional beginning—not urgency, guilt, punishment, or a larger system.
