Calm Execution · Lesson 102 · 8 minutes

Classify one audited instruction pair

Once both attempts followed the plan, read what happened in a fixed order: cue first, start second.

The one skill

Use this only after Lesson 101’s audit says both covered attempts were followed. For each attempt, ask two yes/no questions:

  1. Did the observable cue occur?
  2. If yes, did the exact two-minute action start?

Then apply one label: cue (cue did not occur), start-side (cue occurred, action did not start), none (both occurred), or unclear (the record cannot tell).

Classify before redesigning. A pair supports one already-specified matching test only when the same readable break appears twice.

Why keep cue and action separate?

This is a practical reading rule, not a verdict about you. It preserves the course’s distinction between a stable context and the action that follows it. For background on cue-dependent habit formation, see Gardner, Lally & Wardle (2012).

Applied exercise — classify two audited attempts

Take 5–10 minutes. Put the exact instruction beside two attempts that you already audited as followed. Enter only what the records show.

Instant check

Both attempts followed the instruction. In both, the cue occurred but the two-minute action did not start. What is the pair’s reading?

Ask your teacher if a record feels ambiguous. “Unclear” is usable system data; it does not call for guilt, punishment, or catch-up work.
