Calm Execution · Lesson 81 · 10 minutes

Classify an audited instruction pair

Once both attempts followed the instruction, read each outcome in the same order: cue first, then the two-minute start.

For each readable attempt: no cue = cue; cue but no start = start-side; cue and start = none. Missing evidence = unclear.

The one skill

  1. Use only the two attempts that passed Lesson 80’s enactment audit.
  2. For each, ask: did the observable cue occur? If not, label it cue.
  3. If the cue occurred, ask: did the exact two-minute action start? If not, label it start-side; if yes, label it none.
  4. When either fact cannot be read, label the attempt unclear. Do not infer it from effort or mood.

This is a practical course experiment: separating cue evidence from start evidence helps keep one small plan testable. It is not a diagnosis or a judgment of your ability.

Practice: read the audited pair

Allow 5–10 minutes. Pull out the two records that were both marked followed in Lesson 80.

Close the loop

Write the two labels beside the records. If the same readable break appears twice and you already have one matching bounded test specified, that test is the next move. Otherwise retain the plan and gather two ordinary records. Do not add a new test, catch-up work, guilt, or punishment. Ask your teacher agent if a record is hard to classify.

Background reading: Gardner, Lally & Wardle, “Making health habitual” (2012). The classification rule on this page is a practical course exercise.
