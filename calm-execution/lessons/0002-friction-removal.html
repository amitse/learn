Remove One Barrier Before the Cue

Make the next start less negotiable by preparing one thing in advance.

Win for today: set up one physical or digital condition that lets tomorrow’s two-minute opening step begin with one fewer move.

Starting has a runway

Yesterday you named a cue and a two-minute first action. Today, do not try to become more disciplined. Run a small design experiment: find the first tiny obstruction between the cue and that action, then remove it before the cue.

A habit is more than doing something often; it can become an automatic response to a context repeatedly associated with the behaviour. This practice keeps the cue stable while making the chosen response easier to enter. It does not promise a particular result—your log will tell you whether the setup helps.

Source: Gardner, Lally & Wardle (2012), “Making health habitual” (verified 2026-07-22).

Cue → prepared first object → two-minute action

Choose one barrier, not a renovation

Physical: the notebook is in another room; shoes are buried; the desk is occupied.
Digital: the file is hard to find; the right tab is closed; a distracting site is the default tab.
Decision: you still have to choose which document, question, or task comes first.

Pick the earliest barrier only. “Reorganize my whole workspace” adds a project. “Put the notebook open on the desk” removes one move.

10-minute field exercise

  1. Minute 0–2: Use the planner above for tomorrow’s pre-chosen important action.
  2. Minute 2–7: Do the single setup move now. Stop when the first action is ready; do not turn preparation into the task.
  3. Minute 7–10: Put a one-line entry in your daily start log: date — cue — setup done? yes/no — started? pending.

At tomorrow’s cue, take the two-minute opening step. Then record started: yes/no. If you do not start, describe the barrier that remained. That is system data, not a verdict.
