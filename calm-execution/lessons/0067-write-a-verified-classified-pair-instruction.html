Calm Execution · Lesson 67

Write a verified classified-pair instruction

Turn the two labels from Lesson 66 into one small, auditable instruction for the next two ordinary attempts.

One pair → one next move → same cue and two-minute action → two attempts.

One skill

Write only the move the pair supports. If both readable labels are the same cue or start-side break and you already wrote a matching test, name that one test. Otherwise, retain the current plan and gather two readable attempts.

  • Name the existing observable cue.
  • Name the exact two-minute action.
  • Set a two-attempt boundary.
  • Do not add a new test, duration, catch-up task, or judgment.

This is a practical planning exercise, not a claim about why a particular attempt went as it did. It keeps the next action small enough to audit.

The decision rule

  1. Use only a pair that passed the enactment audit: both attempts were followed.
  2. Use the two Lesson 66 labels: cue, start-side, none, or unclear.
  3. If the same readable break appears twice and a matching test already exists, use that single test for two ordinary attempts.
  4. For every other result, retain the plan and gather two ordinary readable attempts.
