Calm Execution · Lesson 31

Compare two used test records

Read two ordinary attempts without promoting a small sample into a verdict.

One skill: make a restrained next decision

Repeated behaviour in a stable context is relevant to cue-based practice, but this lesson makes no promise about what two records can prove. Treat them as a practical comparison: did the written change happen, and what followed? Source: Gardner, Lally & Wardle (2012).

Read each record in order: test used → cue occurred → two-minute action started. If both records used the same test and neither shows clear added friction, retain it for two more ordinary attempts. Return to the prior plan only for clear added friction. Otherwise, gather ordinary evidence—without a new change.

12-minute applied exercise

  1. Put your one-sentence test instruction beside the two most recent attempts.
  2. For each attempt, mark: test used? · cue? · started?.
  3. Ask one narrow question: did the change clearly add friction? Do not infer more than the records show.
  4. Choose one instruction: retain for two attempts, return to prior plan, or gather two ordinary records.
