Calm Execution · Lesson 23

Consolidate a bounded test

After a test and two ordinary attempts, decide whether to keep the tested link—or whether the same earliest break is clear enough for one new test.

One skill

Read three records in order, then make one decision: keep the tested link, or name one new bounded test only when the same earliest break appears twice.

This is a practical observation exercise, not proof of cause. Research on habit describes repeated behaviour in stable contexts as relevant to cue-driven responding; a few personal records are still only local evidence. Gardner, Lally & Wardle (2012).

10–15 minutes

Applied exercise: make a consolidation card

  1. Place the test record beside the next two ordinary records. Read each: cue occurred?, then two-minute action started?.
  2. Write the earliest break for each record: none, cue, or start-side (setup/opening action).
  3. Choose one result: keep the tested link when the records are workable or mixed; name one new test only if the same earliest break appears in at least two readable records.
  4. Make one ordinary next attempt. Keeping the plan is a complete decision; no catch-up or upgrade is needed.
Example: Test: cue occurred, started. Next: cue occurred, started. Next: cue occurred, started. Earliest breaks: none, none, none. Decision: keep the cue note and current two-minute action. Not: add a longer session because it worked.

Check your consolidation decision

Immediate feedback only; nothing is stored.

Tomorrow’s rule

Keep a workable plan. Revise only after the same earliest break is visible twice—and then test one link, once.

Ask your teacher to help classify an unclear set of records. The aim remains a calm, intentional beginning—not urgency, guilt, punishment, or a bigger system.
