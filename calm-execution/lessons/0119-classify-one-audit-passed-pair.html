Calm Execution · Lesson 119 · 8 minutes

Classify one audit-passed pair

Once both attempts followed the instruction, read the cue first and the two-minute start second.

The one skill

Use this only for a pair that passed yesterday’s enactment audit. For each attempt, choose one outcome label:

Cue = the cue did not occur.
Start-side = the cue occurred but the exact two-minute action did not start.
None = the cue occurred and the action started.
Unclear = the record cannot tell.

Then read the pair, not your character: retain and gather records unless the same readable break appears twice and you already have one matching bounded test specified. This is a practical classification rule, not a verdict. Repetition in a stable context is relevant background for cue-based practice; see Gardner, Lally & Wardle (2012).

Applied exercise — classify the audited pair

Spend 5–10 minutes with the two records that both earned followed. Do not design a new change here. Read cue, then start, for each record.

Instant check
