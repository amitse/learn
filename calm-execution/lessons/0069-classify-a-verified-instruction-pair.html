Calm Execution · Lesson 69

Classify a verified pair

When both attempts followed the same instruction, read each record in the same small order: cue first, then start.

Verified enactment → earliest readable break → one calm next move.

One skill

Classify each of two followed attempts without guessing at causes. Use the record, not your memory:

  • cue — the cue did not occur, or the record says it did not.
  • start-side — the cue occurred, but the two-minute action did not start.
  • none — the cue occurred and the two-minute action started.
  • unclear — a needed fact is absent.

This is a practical record-reading experiment, not a diagnosis or proof of why an attempt went as it did. Repetition in stable contexts can support cue-based behaviour; see Gardner, Lally & Wardle (2012).

The decision boundary

  1. Use this only after Lesson 68’s two labels are both followed.
  2. For each attempt, check cue occurred? before two-minute action started?.
  3. If both readable labels match—two cue or two start-side—use only one already-specified matching test.
  4. For none, mixed labels, or any unclear, retain the current instruction and gather two ordinary readable records.

No catch-up work, new test, or self-judgment is required by this reading.
