Calm Execution · Lesson 84 · 10 minutes

Classify an audited cue-first pair

When both attempts followed the same instruction, read what happened in a fixed order: cue first, then start.

For each audited attempt: no cue = cue; cue happened but the two-minute action did not begin = start-side; both happened = none; a missing fact = unclear.

The one skill

  1. Use this only after Lesson 83 gave followed to both attempts.
  2. Read one record: did the observable cue occur? If not, label it cue.
  3. If it did, ask whether the exact two-minute action began. Label start-side if it did not; none if it did.
  4. Keep a missing detail as unclear. Do not fill it in from memory.

This is a practical course rule for keeping a tiny experiment readable. It is not a verdict about motivation or character.

Practice: read your audited pair

Allow 5–10 minutes. Put the two records that passed your Lesson 83 audit beside you, then choose one label for each.

Close the loop

If the same readable cue or start-side label appears twice, carry forward only one already-specified matching test. For mixed, none, or unclear results, retain the existing cue and exact two-minute action and gather two ordinary records. No catch-up work is needed. Ask your teacher agent if a label is difficult to choose.

Background reading: Gardner, Lally & Wardle, “Making health habitual” (2012). The classification rule on this page is a practical course exercise.
