Calm Execution · Lesson 45

Classify an audited pair

When both attempts followed the instruction, locate the earliest readable break—without turning a pair of records into a verdict.

The one skill

Use this only after Lesson 44’s audit says both attempts followed the exact instruction. For each record, read in one direction: did the cue occur? If yes, did the two-minute action start?

No cue → cue. Cue but no start → start-side. Cue and start → none. Missing evidence → unclear.

This is a practical way to keep a tiny cue-and-action plan observable. Repetition in a stable context is discussed as relevant to cue-linked habit formation by Gardner, Lally & Wardle (2012); this two-record classification is a course decision rule, not proof of cause.

Your 10-minute exercise

  1. Place the two records that passed your instruction audit side by side.
  2. For each, read cue occurred? before two-minute action started?. Select its label below.
  3. Use the feedback to write just one calm next move.
  4. Take the next ordinary attempt; do not add duration, catch-up work, or a second change.

Audited-pair classifier

What counts as success?

A precise label is success. Mixed, working, and unclear pairs all support gathering two more ordinary records with the current plan. Only the same readable break twice makes a previously specified one-link test relevant. Ask your teacher if you want help making a cue or two-minute action easier to record.

Source: Gardner, Lally & Wardle (2012). Evidence is for adjusting the system, never judging the person.
