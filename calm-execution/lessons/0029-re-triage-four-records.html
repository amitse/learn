Calm Execution · Lesson 29

Re-triage four records

Use a small, readable sample to choose restraint—or one exact next test.

One skill: label the earliest break

This is a practical experiment, not a diagnosis. Take four recent ordinary records from your carry-forward plan. For each record, read only:

  1. Was the named test used? If a test is currently retained, note yes/no.
  2. Did the cue occur? If no, label it cue.
  3. Did the two-minute action start? If the cue occurred but the action did not start, label it start-side. If both occurred, label it none.

The decision boundary: retain the current plan when the records are working, mixed, or incomplete. Specify one new bounded test only if the same earliest break appears in at least two readable records.

12-minute applied exercise

  1. Set a 12-minute timer and open four recent records.
  2. Write four labels: none, cue, or start-side. If the current test was not used, write incomplete instead.
  3. Choose one calm instruction for the next ordinary attempt: retain, or one exact cue / setup / opening-action test. Do not change more than one link.

Decision check

Try this sample before you read the answer: none, cue, none, cue. What is the next move?

A complete instruction names either “retain” or one link, one exact change, and what remains stable.

Carry forward: four records are enough for a modest decision, not a verdict. A repeated cue break supports one cue test. A repeated start-side break supports one setup or opening-action test. Everything else supports keeping the plan readable.

Ask your teacher if you want help turning a real four-record pattern into one bounded instruction.
