Calm Execution · Lesson 33

Run a five-record stability check

Use five ordinary attempts to choose between calm retention and one bounded test.

The one skill

Read five recent records in the same order: test used? (if you are retaining a test), cue occurred?, then two-minute action started?. A readable set with no earliest break repeated twice is stable enough to retain—not proof that the system is permanent.

Five readable records → no repeated earliest break → retain the same small plan for two ordinary attempts.

This is a practical decision rule, not a scientific threshold. The course uses stable cues and repeated small actions as an experiment informed by Gardner, Lally & Wardle’s review of habit formation and stable contexts: verified source.

Your 10–15 minute exercise

  1. Collect five recent ordinary records using the current plan. If a retained test is part of the plan, use only records intended to use that same written test.
  2. For each record, confirm test used?. If it was not used or is unclear, stop: keep the instruction and gather two ordinary records. Do not add a new change.
  3. Label each readable record: cue when the cue did not occur; start-side when the cue occurred but the two-minute action did not start; otherwise none.
  4. Use the checker, write its one instruction beside your log, then make one ordinary next attempt. No catch-up work.

Interactive stability checker

Use “not applicable” if the current plan has no bounded test. “Unclear” means the record cannot answer that field.

Keep the result small

Retention means keeping the same cue, two-minute action, and chosen frequency. A repeated break permits only one matching test: cue, or one start-side link (setup or opening action). It does not require more effort.

Ask your teacher a follow-up question if a label is ambiguous. The aim is a readable next attempt, not a perfect explanation.
