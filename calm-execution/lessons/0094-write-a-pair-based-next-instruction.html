Calm Execution · Lesson 94 · 10 minutes

Write a pair-based next instruction

Turn two audited, classified attempts into one calm instruction for the next two ordinary attempts.

The one skill

Write a next instruction that contains exactly four parts:

  1. One move: retain and gather, or one already-specified matching test.
  2. The observable cue.
  3. The exact two-minute action.
  4. A two-attempt boundary.

Mixed, working, or unclear evidence → retain and gather. The same readable cue or start-side break twice → use only one already-specified matching test.

Why keep it this small?

This is a practical experiment in keeping the start ritual cue-led rather than urgency-led. Repetition in a stable context can make behaviour more cue-driven; here, keeping the cue and two-minute action explicit makes the next attempt readable. Gardner, Lally & Wardle (2012).

Applied exercise — make your next instruction

Spend 5–10 minutes with the two labels from Lesson 93. Do not add a duration, output target, catch-up task, or second change.

  1. If both labels are the same readable break and you already specified its matching test, choose one test. Otherwise choose retain and gather.
  2. Copy your existing cue and exact two-minute action.
  3. Write one sentence and use it for the next two ordinary attempts.

Instant check

Pair: A = cue; B = cue. A matching cue test was already specified. Which instruction respects the boundary?

Ask your teacher if the pair is ambiguous. A readable next instruction is enough; the goal remains one calm, intentional start.
