Calm Execution · Lesson 105 · 10 minutes

Classify one audited pair

Once both attempts followed the plan, locate the first observable break—without turning it into a verdict.

The one skill

Use this only when Lesson 104 gave both attempts the label followed. Read each record in one order:

  1. Did the cue occur?
  2. Did the exact two-minute action start?

Label each attempt cue when the cue did not occur; start-side when it occurred but the action did not start; none when both occurred; or unclear when either fact is missing. Do not infer a cause.

Why this narrow order?

Repeated behaviour in a stable context can become more cue-driven, so an observable cue is worth keeping distinct from the response. Gardner, Lally & Wardle (2012) reviews this cue–response account of habit. Today’s labels are a practical reading tool, not a diagnosis or a claim about motivation.

Applied exercise — read the pair

Take 5–10 minutes with the two attempts that passed your audit. For each, answer only from the record. Then use the result below.

Instant check

An audited attempt has cue occurred: yes and two-minute action started: no. Which label fits?

For two matching readable cue or start-side labels, use only one already-specified matching bounded test. For mixed, working, or unclear evidence, retain the current plan and gather two ordinary records. Ask your teacher if a label or record is ambiguous. No guilt, punishment, or catch-up work is needed.
