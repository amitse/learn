Calm Execution · Lesson 63

Classify a verified classified pair

You have audited the instruction. Now read the two outcomes—without redesigning your system from one small pair of records.

First verify enactment. Then read cue occurred?, then two-minute action started?.

One skill

Give each of two followed attempts one earliest readable label:

  • cue — the cue did not occur or is not recorded.
  • start-side — the cue occurred, but the two-minute action did not start.
  • none — cue occurred and action started.
  • unclear — a needed fact is missing. Do not fill it in from memory.

This is a practical reading routine, not a verdict about you. Stable-context repetition can make a behaviour more cue-driven over time; this lesson simply keeps your evidence readable while you practise. Gardner, Lally & Wardle (2012).

Decision rule

  1. Use this only if both attempts passed the prior audit as followed.
  2. Classify each attempt in cue-then-start order.
  3. If the same readable break appears twice (cue or start-side), use only one already-specified matching test.
  4. Otherwise retain the current small plan and gather two ordinary readable attempts. No catch-up, penalty, or extra change.

Try it: 8-minute pair read

Set a timer, place your two audited records beside you, and classify them. This exercise is complete when you have written both labels and one calm next move.

If either attempt was not followed or unclear in the audit, write: “Repeat the exact instruction for two ordinary attempts.” Stop there; do not classify outcomes yet.

Take forward

Read the plan before reading the outcome. When it was followed twice, cue first and start second are enough for a calm decision. Ask me a follow-up question if a record feels ambiguous; ambiguity is information, not a reason to punish yourself.
