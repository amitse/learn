The one skill

Use this only after Lesson 105: both covered attempts were followed, then classified cue-first.

For mixed, working, or unclear labels, write: retain the current plan and gather two ordinary records. Only when the same readable cue or start-side label appears twice may you use one already-specified matching bounded test.

In either case, the instruction must name the same observable cue, the exact two-minute action, and a two-attempt boundary.

Why keep the cue visible?

Repeated behaviour in a stable context can become more cue-driven; that is why this practice keeps the cue distinct from the action. Gardner, Lally & Wardle (2012) reviews this cue–response account of habit. The instruction below is a practical experiment, not a verdict about motivation.
