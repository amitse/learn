Calm Execution · Lesson 74 · 10 minutes

Audit a checkable next instruction

Before interpreting whether a plan worked, check whether you actually used the exact plan you wrote.

For each of the two covered attempts, use one label only: followed, not followed, or unclear.

The one skill

  1. Read the previous instruction exactly as written.
  2. Compare it with attempt 1, then attempt 2. Do not read cue or start outcomes yet.
  3. If both are followed, the pair is ready for the existing cue-then-start classification.
  4. If either is not followed or unclear, repeat the same instruction for two ordinary attempts. No redesign, catch-up, or verdict.

This is a practical measurement rule for your own experiment, not a judgment about effort.

Practice: run the audit

Use your Lesson 73 sentence and its two actual attempts. This should take 5–10 minutes.

Close the loop

Copy the result into your one-line record. Then take the next ordinary attempt. A readable audit is useful evidence; it is not a score.

Questions or a tricky real record? Ask your teacher agent and include the exact instruction plus the two labels.

Background: Gardner, Lally & Wardle (2012), “Making health habitual” discusses habits as cue-driven behaviour in stable contexts. This lesson uses a deliberately small, repeatable cue-and-action practice.
