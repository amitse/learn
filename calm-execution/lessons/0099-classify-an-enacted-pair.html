Calm Execution · Lesson 99 · 8 minutes

Classify an enacted pair

Once the same instruction was followed twice, read each outcome in one fixed order: cue first, start second.

The one skill

Use Lesson 98 only if both covered attempts were labelled followed. For each record, ask two factual questions:

  1. Did the cue occur?
  2. Did the exact two-minute action start?
  • cue — the cue did not occur.
  • start-side — the cue occurred; the exact action did not start.
  • none — cue and action both occurred.
  • unclear — either fact is missing.

Retain and gather another ordinary pair unless the same readable cue or start-side label appears twice and you already have one matching bounded test specified.

Why keep the order fixed?

This is a practical way to keep the record interpretable rather than turning a miss into a personal story. Repetition in a stable context is part of the distinction between cue-driven habits and mere frequency; this lesson keeps the cue visible while you review. Gardner, Lally & Wardle (2012).

Applied exercise — classify your audited pair

Spend 5–10 minutes with the two records that passed Lesson 98. Do not infer missing facts. Make one label for each attempt, then let the tool state the conservative next move.

Covered attempt 1

First read its cue; then read its exact two-minute action.

Covered attempt 2

Again: cue first; action second.

Instant check

Both attempts were followed. Attempt 1: cue occurred, action did not start. Attempt 2: the cue record is missing. How should the pair be handled?

Ask your teacher if a label is hard to assign. The aim is readable system data—not urgency, guilt, punishment, or catch-up work.
