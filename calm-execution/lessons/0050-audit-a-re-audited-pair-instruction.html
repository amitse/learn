Calm Execution · Lesson 50

Audit a re-audited pair instruction

Before reading results, check whether the exact instruction was used on both ordinary attempts.

One skill: separate enactment from outcome

Take the sentence you wrote in Lesson 49 and compare it with each of the two attempts it covered. For each attempt, choose one label:

Followed = the stated next move, cue, and two-minute action happened as written. Not followed = a stated part did not happen. Unclear = the record cannot tell.

If either label is not followed or unclear, repeat the same instruction for two ordinary attempts. Do not interpret cue or start results yet, and do not add a change. If both are followed, the pair is ready for the existing cue/start-side classification.

This course treats a stable cue and small opening action as a practical design choice. A review of habit research distinguishes cue-triggered habits from mere repetition; it does not promise automaticity on a timetable. Gardner, Lally & Wardle (2012).

10-minute applied exercise

  1. Put the exact Lesson 49 instruction beside the two records it covered.
  2. For attempt 1, check the next move, cue, and two-minute action against the sentence. Label it.
  3. Do the same for attempt 2. Use the checker below.
  4. Copy the resulting next move into your log: repeat the same instruction, or classify the now-readable pair.

Pair audit checker

Stopping after the two-minute action remains a valid start. Ask your teacher if a record is hard to label; “unclear” is useful system data, not a failure.
