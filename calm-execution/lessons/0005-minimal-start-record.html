Make a Minimal Start Record

Capture one honest line immediately after the cue—enough evidence to improve the system, not a productivity diary.

Win for today: create a one-line record you can complete in under 30 seconds after tomorrow’s attempt.

Record the attempt, not your worth

Your ritual already has three observable links: the cue, the small setup, and the two-minute first action. A tiny record lets you see which link happened. It is not a score, streak, explanation, or promise to catch up.

cue occurred? → setup done? → started? → one neutral note only if needed

This is a practical experiment, not a claim that tracking by itself solves procrastination: for the next few days, make the record so small that it does not become another barrier. The course’s cue-based design is grounded in the idea that repeated action in a stable context can become more cue-driven; see Gardner, Lally & Wardle (2012), “Making health habitual” (verified 2026-07-25).

The four-field rule

  1. Date: enough to distinguish attempts.
  2. Cue: yes/no—did the chosen event occur and get noticed?
  3. Setup + start: yes/no for each. A start means the pre-chosen physical action began, not that a session was productive.
  4. One note only when useful: name the earliest break and one adjustment for tomorrow. Leave it blank after a clean start.

Keep the same fields for several attempts. Changing the form every day makes comparisons noisier and adds friction.

10-minute field exercise

  1. Minutes 0–2: Open a note, paper log, or calendar entry where you will see it at tomorrow’s cue.
  2. Minutes 2–4: Copy this template exactly: date — cue? y/n — setup? y/n — started? y/n — note:.
  3. Minutes 4–7: Complete the planner above for a recent attempt or a rehearsal. Keep only the four fields.
  4. Minutes 7–10: Put the log beside the prepared first object. Tomorrow, fill it in immediately after the attempt—whether the answer is yes or no.

If you record a no, use Lesson 3’s neutral review: identify the earliest break and test one change tomorrow. Do not add a penalty, a catch-up session, or extra fields.
