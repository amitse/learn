Calm Execution · Lesson 60

Classify a verified pair

Once the same next instruction was followed twice, read each attempt in one fixed order: cue first, then start.

8–12 minutes

One skill

Give each verified attempt one earliest readable label: cue, start-side, none, or unclear.

Order matters: ask “Did the cue occur?” first. If no, label cue. If yes, ask “Did the exact two-minute action start?” If no, label start-side; if yes, label none. Missing facts are unclear—never guessed.

This is a practical reading rule, not proof that a pair establishes a cause. The course’s small, stable cue/action design is informed by the discussion of cue-dependent habits in stable contexts in Gardner, Lally & Wardle (2012).

Real-world exercise

  1. Confirm that both attempts covered by your Lesson 58 instruction were labelled followed in Lesson 59. If not, stop: repeat that exact instruction for two ordinary attempts.
  2. With the two records in front of you, classify each using the fixed order above. This should take 5–10 minutes; do not revise the ritual while reading.
  3. Use the result below. Only two matching, readable cue or start-side labels point to one already-specified matching test. Every other result means retain the instruction and gather two ordinary readable attempts.
