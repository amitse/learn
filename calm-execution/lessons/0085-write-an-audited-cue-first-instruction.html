Calm Execution · Lesson 85 · 10 minutes

Write an audited cue-first instruction

Turn the pair you just classified into one sentence that can be enacted—and checked—over two ordinary attempts.

Use one move only: retain and gather for mixed, workable, or unclear evidence; use one already-specified matching test only when the same readable cue or start-side break appeared twice.

The one skill

  1. Begin with the move supported by your two Lesson 84 labels.
  2. Name the same observable cue and the exact two-minute action.
  3. End with a two-attempt boundary: do this for the next two ordinary attempts.
  4. Do not add a second change, extra duration, or catch-up work. The next job is to audit whether this sentence was followed.

This is a practical course rule for keeping the next small experiment readable. It is not a test of commitment or character.

Practice: draft the next instruction

Allow 5–10 minutes. Keep your classified pair beside you. Write the existing cue and exact two-minute action, then choose the one supported move.

Close the loop

Copy the resulting sentence where you will see it. Use it for two ordinary attempts, then audit enactment before interpreting cue or start outcomes. If the evidence is mixed or incomplete, retaining the small plan is the complete next move. Ask your teacher agent if you are unsure whether a test was already specified.

Background reading: Gardner, Lally & Wardle, “Making health habitual” (2012). The instruction-writing rule on this page is a practical course exercise.
