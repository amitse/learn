Calm Execution · Lesson 86 · 8 minutes

Audit an audited cue-first instruction

Before reading whether the start worked, check whether your exact Lesson 85 instruction was actually used in both covered attempts.

Read the sentence first—not the result. Label each attempt followed, not followed, or unclear.

The one skill

  1. Put your written Lesson 85 sentence beside its two covered records.
  2. For each attempt, compare the stated cue, exact two-minute action, and one next move with what the record shows.
  3. Mark followed only when the available record matches the sentence; mark not followed when it does not; mark unclear when you cannot tell.
  4. If either label is not followed or unclear, repeat the exact sentence for two ordinary attempts. If both are followed, the next lesson can read cue first, then start.

This is a practical course rule: it keeps an outcome from being assigned to a plan that was not clearly enacted. It is not a judgment about effort or character.

Practice: audit the pair

Allow 5–8 minutes. Use your actual sentence and two records. Do not fill gaps from memory.

Close the loop

Write the two labels beside your records. If the pair is not fully verified, repeating the same small instruction is the complete next move—no catch-up work and no redesign. Ask your teacher agent if you want help separating an unclear record from a not-followed one.
