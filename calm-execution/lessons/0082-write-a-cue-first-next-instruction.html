Calm Execution · Lesson 82 · 10 minutes

Write a cue-first next instruction

Turn the two labels from your audit-passed pair into one instruction you can actually enact—and audit—over the next two ordinary attempts.

A checkable instruction names one move + the same observable cue + the exact two-minute action + a two-attempt boundary.

The one skill

  1. Use only the pair that passed Lesson 80’s enactment audit and that you classified in Lesson 81.
  2. If the same readable break appears twice and you already specified its matching bounded test, write that one test as the move.
  3. For every other result—mixed, none, or unclear—write: retain the existing plan and gather two ordinary records.
  4. Copy the sentence somewhere visible. Do not add a second change, catch-up work, guilt, or a verdict about yourself.

This is a practical course rule for keeping one small start ritual testable. It is not a diagnosis or a claim that a single pair proves why a start did or did not happen.

Practice: make the next instruction

Allow 5–10 minutes. Have the two Lesson 81 labels and your existing cue/action in front of you.

Close the loop

Use the sentence for two ordinary attempts, then audit whether it was followed before reading outcomes again. The aim remains one calm, pre-chosen start—not a streak, a punishment, or more output. Ask your teacher agent if a label or a “matching test” is unclear.

Background reading: Gardner, Lally & Wardle, “Making health habitual” (2012). The decision rule on this page is a practical course exercise.
