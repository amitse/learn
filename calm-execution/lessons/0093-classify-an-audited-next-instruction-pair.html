Calm Execution · Lesson 93 · 10 minutes

Classify an audited pair

Once both attempts followed your exact instruction, read what happened in the same order every time: cue first, then start.

The one skill

Give each fully enacted attempt one neutral label:

  • cue — the observable cue did not occur.
  • start-side — the cue occurred, but the exact two-minute action did not start.
  • none — the cue occurred and the two-minute action started.
  • unclear — a needed fact is missing.

Do not interpret output, mood, or character. Classify only the cue and the start.

Why this narrow reading?

This is a practical experiment for protecting the mission from urgency and self-punishment: a readable pair tells you which link, if any, deserves attention. Stable contexts can make behaviour more cue-driven over time; this lesson uses an observable cue so the record can be read without guessing. Gardner, Lally & Wardle (2012).

Applied exercise — classify your last two audited attempts

Use the exact instruction from Lesson 91 only if Lesson 92 marked both covered attempts followed. Spend up to 10 minutes; do not redesign the ritual today.

  1. Write the cue and exact two-minute action at the top of your paper.
  2. For each attempt, answer: “Did the cue occur?” then “Did the action start?”
  3. Give each attempt one label. Copy the pair into your start log.

Instant check

Scenario: Both attempts followed the instruction. In A, the cue happened but the action did not begin. In B, both cue and action happened. What is the pair?

Decision boundary

If the same readable label appears twice and you already have one matching bounded test, that test may be the next move. Otherwise retain the plan and gather another readable pair. An unclear record is a request for better facts, not a verdict.

Ask your teacher if a label feels ambiguous. The goal is one calm, intentional start—not a perfect day.
