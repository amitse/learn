Calm Execution · Lesson 38

Verify a rolling instruction

Before changing the plan again, check whether the instruction from the last review was actually followed.

The one skill

A rolling instruction is useful only when it becomes the next two ordinary attempts. Put the written instruction beside those two records and compare its promises with what happened.

First verify the instruction; only then read the two records for a repeated earliest break.

If the instruction said “keep the plan,” check that the cue, two-minute action, frequency, and any active test stayed the same. If it named one bounded test, check that exact change was used. If that cannot be confirmed, call the evidence incomplete—not a failed plan.

This course’s cue-based framing is informed by Gardner, Lally & Wardle’s review, which distinguishes cue-triggered habitual behaviour from merely frequent behaviour: verified source. The verification rule here is a practical experiment design, not a claim that two records establish a cause.

Your 10-minute exercise

  1. Find the last written rolling instruction and the two attempts it covered.
  2. Underline its one promise: keep the plan, gather readable records, or use this exact bounded test.
  3. For each attempt, mark “followed,” “not followed,” or “unclear.” Do not fill gaps from memory.
  4. Use the checker below. Copy its result beside the two records, then make the next ordinary two-minute attempt—no catch-up work.

Interactive instruction checker

Good enough

“Unclear—repeat the same instruction and gather two readable records” is a successful result. It protects you from explaining an experiment that did not actually happen. Ask your teacher if the written instruction or record fields are too vague to verify.

Verify the instruction first. Then use the familiar two-record boundary: retain, gather evidence, or run one already-specified matching test.
