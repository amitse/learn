Configure slog level by environment

Your logger already has an explicit minimum level. Make that deployment policy configurable without letting raw strings leak into logger construction or HTTP handlers.

Tangible win

You will parse LOG_LEVEL once into a typed slog.Level, pass it through Config, and test default, valid, and invalid settings without changing the real environment.

Level is policy; events are facts

A call site should say what happened: logger.Debug, Info, Warn, or Error. The handler decides which severities a particular deployment emits. That choice belongs at the same configuration boundary as LOG_SOURCE.

TypeScript / Node

type Config = { logLevel: "debug" | "info" | "warn" | "error" };

const logger = createLogger({
  level: config.logLevel,
  format: json(),
});

Go

type Config struct {
    LogLevel slog.Level
}

func newLogger(out io.Writer, cfg Config) *slog.Logger {
    opts := &slog.HandlerOptions{
        Level: cfg.LogLevel,
    }
    return slog.New(slog.NewJSONHandler(out, opts))
}
Keep the boundary clean: LOG_LEVEL is untrusted text. newLogger receives a typed level; it does not call os.Getenv. Handlers do not choose the threshold either.

Let slog.Level parse its own names

slog.Level.UnmarshalText accepts the standard names DEBUG, INFO, WARN, and ERROR (case-insensitively). It also supports documented level offsets such as DEBUG+2. Do not maintain a second hand-written mapping when the type already owns its text format.

func loadLogLevel(lookup Lookup) (slog.Level, error) {
    raw, ok := lookup("LOG_LEVEL")
    if !ok || raw == "" {
        return slog.LevelInfo, nil // deliberate default
    }

    var level slog.Level
    if err := level.UnmarshalText([]byte(raw)); err != nil {
        return 0, fmt.Errorf("parse LOG_LEVEL: %w", err)
    }
    return level, nil
}

// During config loading:
level, err := loadLogLevel(lookup)
if err != nil { return Config{}, err }
cfg.LogLevel = level

Notice the default is explicit. A missing setting means INFO—not accidentally DEBUG because slog.Level's numeric zero value is LevelDebug.

Test parsing separately from output

The injected Lookup seam from Lesson 19 keeps parsing deterministic. First test the configuration contract; then use a buffer-backed handler to test the filtering result. The two tests answer different questions.

func TestLoadLogLevel(t *testing.T) {
    tests := []struct {
        name string; env map[string]string
        want slog.Level; wantErr bool
    }{
        {"missing defaults to info", nil, slog.LevelInfo, false},
        {"debug", map[string]string{"LOG_LEVEL": "debug"}, slog.LevelDebug, false},
        {"invalid is rejected", map[string]string{"LOG_LEVEL": "loud"}, 0, true},
    }
    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            got, err := loadLogLevel(mapLookup(tt.env))
            if (err != nil) != tt.wantErr { t.Fatalf("err=%v", err) }
            if !tt.wantErr && got != tt.want { t.Fatalf("got %v, want %v", got, tt.want) }
        })
    }
}

Test the event’s presence or absence—not the handler’s internal fields, timestamp, or full serialized JSON line.
