The problem with DefaultServeMux

In Lesson 3 you used http.HandleFunc and passed nil to http.ListenAndServe. That works, but it registers routes on a global singleton called DefaultServeMux. This is fine for toy code but creates problems in real programs:

  • Third-party packages you import can silently register routes on the same mux
  • You can't run multiple servers with different route trees in the same process
  • It's harder to test handlers in isolation

The fix is one line: create your own mux.

TypeScript (Express)
import express from 'express'
const app = express()  // isolated router
app.get('/', handler)
app.listen(8080)
Go (net/http)
mux := http.NewServeMux()  // isolated mux
mux.HandleFunc("/", handler)
http.ListenAndServe(":8080", mux)

Ref: pkg.go.dev — http.NewServeMux

Notice: you now pass mux (not nil) to ListenAndServe. That's the only change.

Exact vs. subtree patterns

Go's ServeMux has two kinds of path patterns — and mixing them up is the #1 routing bug for beginners:

Pattern Type Matches
"/users" Exact /users only
"/users/" Subtree /users/, /users/42, /users/42/posts …
"GET /users/{id}" Exact + method + param GET /users/42, GET /users/bob …
Gotcha: Registering "/users/" (subtree) also catches /users with a redirect — which can surprise you. If you want only /users, use the exact form (no trailing slash).

Go 1.22: method + path parameters

Go 1.22 (released Feb 2024) added enhanced routing patterns to the standard ServeMux. You can now restrict a route to a specific HTTP method and use {name} wildcards directly in the pattern string — no third-party router needed for most apps.

mux.HandleFunc("GET /users/{id}", getUserHandler)
mux.HandleFunc("DELETE /users/{id}", deleteUserHandler)
mux.HandleFunc("GET /users", listUsersHandler)

Ref: go.dev — Routing Enhancements for Go 1.22

Before 1.22, you'd have to check r.Method manually inside the handler. Now the mux does it for you — a request to the wrong method gets a 405 Method Not Allowed automatically.

Extracting path parameters

Once you've declared a {name} wildcard in your pattern, extract it inside the handler with r.PathValue("name"):

TypeScript (Express)
app.get('/users/:id', (req, res) => {
  const id = req.params.id
  res.json({ id })
})
Go (net/http 1.22+)
mux.HandleFunc("GET /users/{id}",
  func(w http.ResponseWriter, r *http.Request) {
    id := r.PathValue("id")
    fmt.Fprintf(w, "user: %s", id)
  })

Ref: pkg.go.dev — Request.PathValue

r.PathValue returns an empty string if the wildcard isn't present. Always validate it — a missing or non-numeric ID should return a 400, not a panic.

Full working example

Here's a complete, runnable server with three routes. Paste this into main.go in an initialized module and run with go run ..

package main

import (
	"fmt"
	"log"
	"net/http"
)

func main() {
	mux := http.NewServeMux()

	// GET /users — list all users
	mux.HandleFunc("GET /users", func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprintln(w, "[alice, bob, carol]")
	})

	// GET /users/{id} — get one user
	mux.HandleFunc("GET /users/{id}", func(w http.ResponseWriter, r *http.Request) {
		id := r.PathValue("id")
		if id == "" {
			http.Error(w, "missing id", http.StatusBadRequest)
			return
		}
		fmt.Fprintf(w, "user: %s\n", id)
	})

	// DELETE /users/{id}
	mux.HandleFunc("DELETE /users/{id}", func(w http.ResponseWriter, r *http.Request) {
		id := r.PathValue("id")
		fmt.Fprintf(w, "deleted user: %s\n", id)
	})

	log.Println("listening on :8080")
	log.Fatal(http.ListenAndServe(":8080", mux))
}
Try it: Run the server, then in a second terminal: 
curl localhost:8080/users
curl localhost:8080/users/42
curl -X DELETE localhost:8080/users/42
curl -X POST localhost:8080/users/42   # → 405 Method Not Allowed

Cheat sheet

What you want How to do it
New, isolated mux mux := http.NewServeMux()
Match GET /users exactly mux.HandleFunc("GET /users", h)
Match any method on /users mux.HandleFunc("/users", h)
Path parameter {id} pattern: "GET /users/{id}"
Read path parameter r.PathValue("id")
Use the custom mux http.ListenAndServe(":8080", mux)
Catch-all subtree trailing slash: "/static/"
