Go HTTP Server · Lesson 58 · ~8 minutes

Decode the error event,
not just its text

Lesson 57 proved a private cause reached your logs. Now make that test robust: decode the JSON event and assert the event contract—level, stable message, and error field.

Win: turn a buffer of JSON logs into one decoded event and test only the fields your server owns.

Why a substring test is not enough

Too broad

if !strings.Contains(logs.String(),
    private.Error()) { ... }

It proves some bytes appeared. A changed message, wrong level, or malformed event can still slip through.

Contract-level

var got logEvent
json.Unmarshal(line, &got)
// assert got.Level, got.Msg,
// and got.Error

It checks the shape an operator or log collector actually consumes—without coupling to timestamps.

slog.NewJSONHandler emits one JSON object followed by a newline per record. In a focused test with one logged error, trim the newline, decode the object, then assert selected fields.

TS ↔ Go: parse the structured payload

TypeScript / Node

const event = JSON.parse(logLine);
expect(event.level).toBe("error");
expect(event.msg).toBe("log-level change failed");
expect(event.error).toContain(privateText);

Go

var event logEvent
if err := json.Unmarshal(line, &event); err != nil {
    t.Fatal(err)
}
if event.Level != "ERROR" { ... }
if event.Msg != "log-level change failed" { ... }

Use a deliberately small decoder type

The JSON handler includes dynamic fields such as time. Do not mirror the entire handler output. Decode only the stable fields this route promises.

type logEvent struct {
    Level string `json:"level"`
    Msg   string `json:"msg"`
    Error string `json:"error"`
}

func TestSetLevel_logsStructuredUnexpectedError(t *testing.T) {
    var logs bytes.Buffer
    logger := slog.New(slog.NewJSONHandler(&logs, nil))
    private := errors.New("dial tcp db.internal:5432: refused")
    h := newSetLevelHandler(&controlSpy{err: private}, logger)

    r := httptest.NewRequest(http.MethodPut, "/ops/log-level", nil)
    r = r.WithContext(withOperator(r.Context()))
    w := httptest.NewRecorder()
    h.ServeHTTP(w, r)

    line := bytes.TrimSpace(logs.Bytes())
    var got logEvent
    if err := json.Unmarshal(line, &got); err != nil {
        t.Fatalf("decode log event: %v\nlog: %s", err, line)
    }
    if got.Level != "ERROR" { t.Errorf("level = %q, want ERROR", got.Level) }
    if got.Msg != "log-level change failed" { t.Errorf("msg = %q", got.Msg) }
    if got.Error != private.Error() { t.Errorf("error = %q", got.Error) }
}
Keep the public assertion: this complements—not replaces—the Lesson 57 check that w.Body excludes private.Error(). One test can assert both the safe HTTP response and the decoded private log event.

Three choices that keep the test durable

  1. Decode one record: keep the fixture focused so one handler invocation emits one line.
  2. Assert owned fields: event level, msg, and error are this route's contract.
  3. Ignore volatile fields: do not assert the timestamp, source path, or exact serialized JSON order.

Why decode into a small logEvent struct?

Carry forward: logs are structured data. For an unexpected HTTP failure, preserve the two-audience boundary and test the operator event by decoding its owned fields, not by snapshotting a whole line.
