Log structured success
without changing success

Your application boundary now records a structured unexpected failure and preserves its cause. Complete the matching contract: when Run succeeds, emit one stable success event—then return nil unchanged.

Tangible win: add and test one slog completion event that includes process identity while keeping the success path transparent.

One concept: a success event is evidence, not a new result

TypeScript mental model

After await run() resolves, log logger.info({version, revision}, "HTTP server stopped cleanly"), then let the promise resolve. A log should not turn a successful lifecycle into a different value.

Go

After run() returns nil, call logger.Info with named fields and return nil. Keep the non-nil branch for the failure event and wrapped error.

The event belongs beside the failure branch at the application boundary. It does not mean that every handler completed successfully; it means the lifecycle owner reported normal completion.

The narrow success branch

func runApp(run func() error, logger *slog.Logger) error {
    if err := run(); err != nil {
        logger.Error("HTTP server stopped unexpectedly",
            slog.Any("error", err),
            slog.String("version", moduleVersion()),
            slog.String("revision", revisionForLog()),
        )
        return fmt.Errorf("run HTTP server: %w", err)
    }

    logger.Info("HTTP server stopped cleanly",
        slog.String("version", moduleVersion()),
        slog.String("revision", revisionForLog()),
    )
    return nil
}

Keep the message stable and put changing data in attributes. Info is appropriate because normal completion is informational; do not manufacture an error, and do not wrap nil.

Test exactly the success contract

func TestRunAppLogsCleanStop(t *testing.T) {
    var out bytes.Buffer
    logger := slog.New(slog.NewTextHandler(&out, nil))
    called := false

    err := runApp(func() error {
        called = true
        return nil
    }, logger)

    if err != nil { t.Fatalf("runApp() error = %v, want nil", err) }
    if !called { t.Fatal("run was not called") }
    got := out.String()
    for _, want := range []string{
        "level=INFO", `msg="HTTP server stopped cleanly"`,
        "version=", "revision=",
    } {
        if !strings.Contains(got, want) { t.Errorf("log missing %q:\n%s", want, got) }
    }
}

The injected closure makes clean completion deterministic. This test deliberately does not re-test the failure branch, listener shutdown mechanics, or identity precedence—it establishes only that success stays successful and is observable.

  1. Inject a buffer-backed *slog.Logger.
  2. Inject a func() error that records its call and returns nil.
  3. Assert the returned error is nil.
  4. Assert one INFO completion message and its version/revision fields.
