Wrap a downstream transport error—without losing its cause

Your outbound helper now creates a fresh request and carries the selected request ID. Its next job is to make a failed dependency call understandable to the application while preserving the original error for cancellation and timeout checks.

Tangible win: return an error that says which operation failed, then prove callers can still recognize context.DeadlineExceeded with errors.Is.

Context for people; identity for programs

A bare transport error may say only that a deadline expired. At the dependency boundary, add a stable operation label such as get profile. But do not replace the error with a formatted string: callers need the original cause to decide whether it was cancellation, timeout, or something else.

Rule: use fmt.Errorf("get profile: %w", err). The %w verb wraps err; errors.Is can walk that chain. Plain %v only prints text and loses that machine-readable relationship.

Same intention, different idiom

TypeScript / Node

try {
  return await fetch(profileURL, { signal });
} catch (err) {
  throw new Error("get profile", { cause: err });
}

// later: inspect err.cause

Go

res, err := client.Do(req)
if err != nil {
    return nil, fmt.Errorf("get profile: %w", err)
}
return res, nil

// later: errors.Is(err, cause)

Both add an operation boundary while retaining the underlying failure. In Go, %w is the deliberate signal that the cause belongs in the error chain; it is not merely string formatting.

A tiny adapter

func getProfile(ctx context.Context, client *http.Client, url string) (*http.Response, error) {
    req, err := newDownstreamRequest(ctx, url) // Lesson 67 helper
    if err != nil {
        return nil, fmt.Errorf("build profile request: %w", err)
    }

    res, err := client.Do(req)
    if err != nil {
        return nil, fmt.Errorf("get profile: %w", err)
    }
    return res, nil
}

The two operations are intentionally different: failure to build a URL is not failure to perform a network call. Keep the public HTTP error mapping outside this helper; this layer returns a useful application error, while the route decides what is safe to show a client.

Test the preserved cause, not just the sentence

func TestGetProfileWrapsDeadline(t *testing.T) {
    cause := context.DeadlineExceeded
    client := &http.Client{Transport: roundTripFunc(func(*http.Request) (*http.Response, error) {
        return nil, cause
    })}

    _, err := getProfile(context.Background(), client, "https://profiles.example")
    if err == nil || !errors.Is(err, cause) {
        t.Fatalf("errors.Is(err, deadline) = false; err = %v", err)
    }
    if !strings.Contains(err.Error(), "get profile") {
        t.Fatalf("error = %q; want operation context", err)
    }
}

A small RoundTripper fake avoids a real network and forces the exact transport failure. The first assertion protects behavior; the second protects the operator-facing context.

Quick check
