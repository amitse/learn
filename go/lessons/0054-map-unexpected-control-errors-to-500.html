Map unexpected control errors to 500

Your operations handler already distinguishes missing identity (401), forbidden identity (403), and success (204). Add exactly one remaining branch: an unexpected failure from the log-level control becomes a generic 500—without returning internal error text to the caller.

Tangible win

You will add one table row to the existing httptest: an authenticated operator plus a sentinel internal error must produce 500 Internal Server Error, an empty response body, and one control call.

Errors are not all client responses

ErrForbidden is an expected domain outcome, so the handler can deliberately map it to 403. A storage, audit-sink, or other control failure is not an authorization result. It is an internal failure: record its detail in server-side logs and give the HTTP client only a stable 500 response.

TypeScript / Express

try {
  await control.set(principal, "debug");
  res.sendStatus(204);
} catch (err) {
  if (err === forbidden) return res.sendStatus(403);
  logger.error({ err }, "log level change failed");
  res.sendStatus(500); // no err.message
}

Go / net/http

if err := control.Set(r.Context(), p, slog.LevelDebug); err != nil {
    if errors.Is(err, ErrForbidden) {
        http.Error(w, "forbidden", http.StatusForbidden)
        return
    }
    logger.Error("log level change failed", "error", err)
    w.WriteHeader(http.StatusInternalServerError)
    return
}
w.WriteHeader(http.StatusNoContent)
Order matters. Check the known sentinel with errors.Is first. The fallback branch then safely handles every other non-nil error, including a wrapped failure.

Add the fourth row

Reuse the verified-operator context from Lesson 53. The spy supplies an internal sentinel so this test remains a handler test, not a test of an audit sink.

var errAuditUnavailable = errors.New("audit sink: dial tcp 10.0.0.7: refused")

{

// After ServeHTTP:
if body := w.Body.String(); body != tt.wantBody {

Choose one response-body policy and test it. http.Error writes a text body. If your route’s contract is an empty 500, use w.WriteHeader(http.StatusInternalServerError), as above. Do not accidentally expose err.Error() merely because it is convenient.

Why errors.Is?

Controls can add context with fmt.Errorf("audit level change: %w", ErrForbidden). Equality would miss that wrapped sentinel; errors.Is walks the error chain. It preserves the intentional 403 branch while unknown errors fall through to 500.
