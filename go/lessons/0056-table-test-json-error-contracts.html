Table-test JSON error contracts

Lesson 55 gave your API one error body. Now protect it at the route boundary: each failing outcome must select the right status, JSON message, and safe public surface.

Tangible win

You will add error rows to an existing httptest table and decode the response into errorResponse, proving an internal cause never reaches a client.

Test what a client actually receives

Testing writeJSONError once is useful, but the handler can still choose the wrong status or message. A handler table tests the public contract at the decision point: request state → selected HTTP response.

Extend the existing table

Keep the control spy from Lesson 53. Add expected public fields to each row. The only special case is 204: it deliberately has no JSON body, so the test skips decoding it.

tests := []struct {
    name       string
    ctx        context.Context
    controlErr error
    wantStatus int
    wantError  string // empty means: no body expected
}{
    {
        name:       "missing claims",
        ctx:        context.Background(),
        wantStatus: http.StatusUnauthorized,
        wantError:  "unauthorized",
    },
    {
        name:       "unexpected control error is generic",
        ctx:        verifiedOperatorContext(),
        controlErr: errors.New("postgres: password=secret"),
        wantStatus: http.StatusInternalServerError,
        wantError:  "internal server error",
    },
}

Decode—and prove the private string is absent

t.Run(tc.name, func(t *testing.T) {
    control := &controlSpy{err: tc.controlErr}
    h := newOperationsHandler(control, logger)
    req := httptest.NewRequest(http.MethodPut, "/ops/log-level", nil).
        WithContext(tc.ctx)
    w := httptest.NewRecorder()

    h.ServeHTTP(w, req)

    if w.Code != tc.wantStatus { t.Fatalf("status = %d", w.Code) }
    if tc.wantError == "" { return } // 204 case
    if got := w.Header().Get("Content-Type"); got != "application/json" {
        t.Fatalf("Content-Type = %q", got)
    }
    var body errorResponse
    if err := json.NewDecoder(w.Body).Decode(&body); err != nil { t.Fatal(err) }
    if body.Error != tc.wantError { t.Fatalf("error = %q", body.Error) }
    if strings.Contains(w.Body.String(), "password=secret") {
        t.Fatal("response leaked internal error")
    }
})
Decode before asserting. JSON has insignificant whitespace and encoding order can change as a response grows. Decoding asserts the API meaning instead of its incidental byte formatting.
Scope the no-leak assertion. Use a distinctive fake internal value such as password=secret, then require that exact value not to occur in the response. Do not make a vague assertion that the body “looks safe.”
