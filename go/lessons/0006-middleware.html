Middleware in Go

Wrap handlers to add logging, headers, and auth — without repeating yourself.

The Problem Middleware Solves

In lessons 3–5 you wrote several handlers. Every single one needed the same boilerplate:

w.Header().Set("Content-Type", "application/json")
// ...same thing in every handler

In Express/TypeScript, you solve this with app.use() — a piece of middleware that runs for every request. Go has the same pattern, just more explicit.

The Middleware Signature

A Go middleware is simply a function that takes a handler and returns a handler:

func MyMiddleware(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        // ① do something before the handler
        next.ServeHTTP(w, r)  // ② call the real handler
        // ③ optionally do something after
    })
}
Key types to know:
  • http.Handler — an interface with one method: ServeHTTP(w, r)
  • http.HandlerFunc — a function type that implements http.Handler. Lets you use a plain function as a handler.
  • next.ServeHTTP(w, r) — how you pass control to the wrapped handler

Compare that with Express middleware in TypeScript:

TypeScript (Express)
// app.use() registers globally
app.use((req, res, next) => {
  // before
  next();
  // after (rarely useful)
});
Go
// wrap a specific handler
func MyMW(next http.Handler) http.Handler {
  return http.HandlerFunc(
    func(w http.ResponseWriter, r *http.Request) {
      // before
      next.ServeHTTP(w, r)
      // after
    })
}
Why no global app.use()? Go's net/http doesn't have a global middleware registry. Instead you compose middleware at the point of use — which actually makes dependencies more explicit. Frameworks like chi add back the Use() pattern if you prefer it.

Example 1 — Logger Middleware

Logs the HTTP method, path, and how long the handler took:

import (
    "fmt"
    "net/http"
    "time"
)

func Logger(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        start := time.Now()

        next.ServeHTTP(w, r)   // call the real handler

        fmt.Printf("%s %s %s\n", r.Method, r.URL.Path, time.Since(start))
    })
}

Notice time.Since(start) runs after next.ServeHTTP — because it appears after that line in the returned function.

Example 2 — JSON Headers Middleware

Eliminates the repeated w.Header().Set("Content-Type", "application/json") from every handler:

func JSONContentType(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        w.Header().Set("Content-Type", "application/json")
        next.ServeHTTP(w, r)
    })
}

Now your handlers only encode the JSON — no more header boilerplate.

Chaining Middleware

Middleware composes by nesting — outermost runs first:

func main() {
    mux := http.NewServeMux()
    mux.HandleFunc("/users", listUsers)

    // Apply both middleware to the whole mux
    handler := Logger(JSONContentType(mux))
    //           ↑ outer         ↑ inner

    http.ListenAndServe(":8080", handler)
}
Request → Logger (before) → JSONContentType (sets header) → listUsers handler
Response ← Logger (after: prints duration) ← JSONContentType (returns) ← listUsers handler
Header ordering rule (from lesson 3): w.Header().Set() must be called before writing the body. Setting Content-Type in middleware is safe because middleware runs before the handler. If you tried to set it after next.ServeHTTP(), it would be too late — the headers would already be sent.

Applying Middleware to a Single Route

You don't have to apply middleware to the whole mux. Wrap just one handler:

mux.Handle("/admin", RequireAuth(http.HandlerFunc(adminHandler)))
mux.HandleFunc("/health", healthHandler) // no auth needed

Note: mux.Handle() takes an http.Handler, while mux.HandleFunc() takes a plain function. Use http.HandlerFunc(yourFunc) to convert when needed.

Full TS ↔ Go Comparison

TypeScript (Express)
// Global middleware
app.use(loggerMiddleware);
app.use(express.json());

// Per-route middleware
app.get(
  "/admin",
  requireAuth,       // middleware
  adminController    // handler
);

// Middleware signature
(req: Request,
 res: Response,
 next: NextFunction) => void
Go
// Global middleware (wraps mux)
handler := Logger(JSONContentType(mux))

// Per-route middleware
mux.Handle(
  "/admin",
  RequireAuth(           // middleware
    http.HandlerFunc(adminHandler)), // handler
)

// Middleware signature
func(next http.Handler) http.Handler
