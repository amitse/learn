JWT Middleware

Protect your HTTP routes with JSON Web Tokens — without a framework

Progress:

🎯 What you'll build

A reusable JWT middleware function that reads a Bearer token from the Authorization header, validates it with golang-jwt/jwt, and injects the parsed claims into the request context — so any downstream handler can grab userID without touching the token again.

Why this matters for your server: Every API that stores user data needs auth. JWT is stateless — no DB lookup per request — which makes it fast and easy to deploy. After this lesson you can lock any route behind AuthMiddleware(handler).

1 — How JWT works (30-second version)

A JWT is three base64url-encoded JSON objects joined by dots:

// HEADER.PAYLOAD.SIGNATURE
eyJhbGciOiJIUzI1NiJ9
  .eyJ1c2VySUQiOjQyLCJleHAiOjE3MjAwMDAwMDB9
  .V9nGNWVX...

The server never stores the token. Instead it verifies the signature using a shared secret. If the signature matches, the payload is trustworthy. jwt.io/introduction →

2 — TypeScript vs Go: the mental model

TypeScript (express-jwt / jsonwebtoken)
import jwt from 'jsonwebtoken'

const payload = jwt.verify(
  token, SECRET
) as { userID: number }

// Attach to req, then next()
req.user = payload
Go (golang-jwt/jwt)
import "github.com/golang-jwt/jwt/v5"

token, err := jwt.ParseWithClaims(
  raw, &Claims{},
  func(t *jwt.Token) (any, error) {
    return []byte(SECRET), nil
  },
)
// Attach to context, not the request
ctx = context.WithValue(ctx, key, claims)

Two key differences: Go uses context (not a mutable request object) to pass data downstream, and the secret is returned from a function (the keyfunc) — which lets you swap in asymmetric keys without changing call sites.

4 — Define your Claims struct

package auth

import "github.com/golang-jwt/jwt/v5"

// Claims embeds the standard claims (exp, iat, sub…)
// and adds your own fields.
type Claims struct {
    UserID int64  `json:"userID"`
    Email  string `json:"email"`
    jwt.RegisteredClaims        // embedded: Expiry, IssuedAt, etc.
}

Embedding jwt.RegisteredClaims gives you automatic expiry checking for free — the library validates exp before handing you the parsed struct.

5 — Sign a token (login endpoint)

func SignToken(userID int64, email string, secret string) (string, error) {
    claims := &Claims{
        UserID: userID,
        Email:  email,
        RegisteredClaims: jwt.RegisteredClaims{
            ExpiresAt: jwt.NewNumericDate(time.Now().Add(24 * time.Hour)),
            IssuedAt:  jwt.NewNumericDate(time.Now()),
        },
    }
    token := jwt.NewWithClaims(jwt.SigningMethodHS256, claims)
    return token.SignedString([]byte(secret))
}

6 — Context key type (avoid collisions)

// Use an unexported type for context keys to prevent third-party packages
// from accidentally reading or overwriting your values.
type contextKey string

const ClaimsKey contextKey = "claims"
Why a custom type? context.WithValue compares keys using ==. If two packages both use the plain string "claims", they'll accidentally share the same slot. A private type makes collisions impossible.

7 — The middleware function

func AuthMiddleware(secret string) func(http.Handler) http.Handler {
    return func(next http.Handler) http.Handler {
        return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
            raw := r.Header.Get("Authorization")
            if !strings.HasPrefix(raw, "Bearer ") {
                http.Error(w, "missing token", http.StatusUnauthorized)
                return
            }
            raw = strings.TrimPrefix(raw, "Bearer ")

            claims := &Claims{}
            _, err := jwt.ParseWithClaims(raw, claims,
                func(*jwt.Token) (any, error) {
                    return []byte(secret), nil
                },
            )
            if err != nil {
                http.Error(w, "invalid token", http.StatusUnauthorized)
                return
            }

            ctx := context.WithValue(r.Context(), ClaimsKey, claims)
            next.ServeHTTP(w, r.WithContext(ctx))
        })
    }
}

This follows the factory pattern from Lesson 6 — AuthMiddleware(secret) returns a func(http.Handler) http.Handler so it composes cleanly with other middleware.

8 — Reading claims in a protected handler

func MeHandler(w http.ResponseWriter, r *http.Request) {
    claims, ok := r.Context().Value(ClaimsKey).(*Claims)
    if !ok {
        http.Error(w, "unauthorized", http.StatusUnauthorized)
        return
    }
    // claims.UserID and claims.Email are now available
    json.NewEncoder(w).Encode(map[string]any{
        "userID": claims.UserID,
        "email":  claims.Email,
    })
}
Always type-assert with the two-return form (v, ok := ctx.Value(k).(T)). A one-return assert panics if the value is absent or the wrong type.

9 — Wiring it all together

func main() {
    secret := os.Getenv("JWT_SECRET")

    mux := http.NewServeMux()

    // Public routes — no middleware
    mux.HandleFunc("POST /login", loginHandler)

    // Protected routes — wrapped in AuthMiddleware
    auth := auth.AuthMiddleware(secret)
    mux.Handle("GET /me",      auth(http.HandlerFunc(MeHandler)))
    mux.Handle("GET /posts",   auth(http.HandlerFunc(PostsHandler)))

    http.ListenAndServe(":8080", mux)
}
