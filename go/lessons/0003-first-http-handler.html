Your First HTTP Handler

No framework needed. Go's standard library ships a full HTTP server. This lesson wires one up from scratch.

Goal: By the end you can write a Go HTTP handler, register it, and run a server that responds to requests — the core pattern every Go HTTP server is built on.

1. The Pattern in 10 Lines

Before dissecting anything, here's the complete working server:

package main

import (
    "fmt"
    "net/http"
)

func hello(w http.ResponseWriter, r *http.Request) {
    fmt.Fprintln(w, "Hello, world!")
}

func main() {
    http.HandleFunc("/", hello)
    http.ListenAndServe(":8080", nil)
}

Save this as main.go, then:

go run .
# in another terminal:
curl http://localhost:8080/
# → Hello, world!
✓ No install step
net/http is part of Go's standard library — it ships with the Go toolchain. No go get needed.

2. Anatomy of a Handler

A handler is just a function with this exact signature:

func hello(w http.ResponseWriter, r *http.Request) { ... }
↑ write your response here               ↑ everything about the incoming request

Two parameters, always in this order:

Parameter Type What you do with it
w http.ResponseWriter Write the response — status code, headers, body
r *http.Request Read the request — method, URL, headers, body

http.ResponseWriter is an interface (more on those in a later lesson). For now, think of it as something you can write bytes into. http.Request is a plain struct with all the request data.

3. TS → Go: Side-by-Side

If you've used Express, this maps almost 1:1:

TypeScript (Express)
Go (net/http)
import express from 'express'
const app = express()

app.get('/', (req, res) => {
  res.send('Hello, world!')
})

app.listen(8080)
import "net/http"

func hello(
  w http.ResponseWriter,
  r *http.Request,
) {
  fmt.Fprintln(w, "Hello, world!")
}

http.HandleFunc("/", hello)
http.ListenAndServe(":8080", nil)
// read the method
req.method  // "GET", "POST"…

// read the URL path
req.path    // "/users/42"
// read the method
r.Method    // "GET", "POST"…

// read the URL path
r.URL.Path  // "/users/42"
res.status(404)
res.send('Not found')
w.WriteHeader(http.StatusNotFound)
fmt.Fprintln(w, "Not found")
⚠ Order matters: headers before body
In Go, you must call w.WriteHeader(code) before writing the body. Once you write bytes to w, Go sends a 200 automatically. Calling WriteHeader after writing the body has no effect — unlike Express where you can chain freely.

4. Reading Request Info

func info(w http.ResponseWriter, r *http.Request) {
    // HTTP method: "GET", "POST", "PUT", etc.
    method := r.Method

    // The URL path: "/users/42"
    path := r.URL.Path

    // A query param: /search?q=go
    q := r.URL.Query().Get("q")

    // A request header
    ua := r.Header.Get("User-Agent")

    fmt.Fprintf(w, "method=%s path=%s q=%s ua=%s\n",
        method, path, q, ua)
}

Try registering this as http.HandleFunc("/info", info) and hitting curl "http://localhost:8080/info?q=go".

5. Setting Response Headers

Headers are set via w.Header().Set() — and must be called before WriteHeader or the first body write:

func jsonReply(w http.ResponseWriter, r *http.Request) {
    w.Header().Set("Content-Type", "application/json")
    w.WriteHeader(http.StatusOK)          // 200 — optional, this is the default
    fmt.Fprintln(w, `{"ok": true}`)
}

You'll do real JSON encoding with encoding/json in Lesson 5 — but for now, fmt.Fprintln is fine for a string body.

6. What is nil in ListenAndServe?

http.ListenAndServe(":8080", nil)

The second argument is the http.Handler to use as the router. Passing nil tells Go to use the DefaultServeMux — a global router that http.HandleFunc registers handlers on.

Think of DefaultServeMux like Express's default app instance. You'll eventually replace it with a custom mux for more control (Lesson 4), but for now nil is exactly right.

💡 Full picture
http.HandleFunc("/", hello) is shorthand for http.DefaultServeMux.HandleFunc("/", hello). The two are identical.

7. Putting It Together

A tiny server with two routes:

package main

import (
    "fmt"
    "net/http"
)

func home(w http.ResponseWriter, r *http.Request) {
    fmt.Fprintln(w, "Welcome!")
}

func status(w http.ResponseWriter, r *http.Request) {
    w.Header().Set("Content-Type", "application/json")
    fmt.Fprintln(w, `{"status": "ok"}`)
}

func main() {
    http.HandleFunc("/", home)
    http.HandleFunc("/status", status)

    fmt.Println("Server running on :8080")
    http.ListenAndServe(":8080", nil)
}
go run .
curl http://localhost:8080/          # → Welcome!
curl http://localhost:8080/status    # → {"status": "ok"}
