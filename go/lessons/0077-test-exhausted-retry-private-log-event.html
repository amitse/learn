Test the exhausted-retry private log event

Lesson 76 made the client contract safe: a failed profile dependency becomes a stable 502. Now protect the operator contract too: one structured event that preserves the selected request ID and the private cause.

Tangible win: capture one JSON slog record, decode only the fields this handler owns, and prove that the 502 path is correlated and diagnosable.

Test data, not rendered log text

A JSON handler produces one JSON object per event. Treat that object as a narrow contract: the stable message, the selected request_id, and its error attribute. Do not assert timestamps, key order, or the whole rendered line; those are formatter details rather than this route’s behavior.

Own only what the handler promises: msg == "profile dependency failed", the request ID selected at the inbound boundary, and a private error attribute containing the diagnostic cause.

Capture and decode one event

type profileFailureEvent struct {
    Msg       string `json:"msg"`
    RequestID string `json:"request_id"`
    Error     string `json:"error"`
}

func TestProfileHandler_ExhaustedRetryLogsPrivateEvent(t *testing.T) {
    var logs bytes.Buffer
    logger := slog.New(slog.NewJSONHandler(&logs, nil))
    private := errors.New("dial profile.internal: refused")
    get := func(context.Context, string) (Profile, error) {
        return Profile{}, fmt.Errorf("get profile: %w", private)
    }

    rr := httptest.NewRecorder()
    req := httptest.NewRequest(http.MethodGet, "/profiles/42", nil)
    req = req.WithContext(context.WithValue(
        req.Context(), requestIDKey{}, "req-test-42"))
    profileHandler(get, logger).ServeHTTP(rr, req)

    var got profileFailureEvent
    if err := json.Unmarshal(bytes.TrimSpace(logs.Bytes()), &got); err != nil {
        t.Fatal(err)
    }
    if got.Msg != "profile dependency failed" { t.Fatalf("msg = %q", got.Msg) }
    if got.RequestID != "req-test-42" { t.Fatalf("request ID = %q", got.RequestID) }
    if !strings.Contains(got.Error, private.Error()) { t.Fatalf("error = %q", got.Error) }
}

The recorder still lets you assert http.StatusBadGateway and the safe JSON body from Lesson 76. This test adds the complementary private output: it proves the same handler branch emitted an event that operators can correlate.

Both approaches capture a logger transport and inspect structured data. Go’s buffer plus JSON decoder keeps the test local—no global logger, collector, or substring check against an entire log line.

Keep public and private assertions separate

The dependency error should occur in the decoded private event; it must not occur in the HTTP response. That is not a contradiction. It verifies the deliberate boundary: the client sees a stable gateway message, while the server retains enough detail to investigate.

if rr.Code != http.StatusBadGateway { t.Fatalf("status = %d", rr.Code) }
if strings.Contains(rr.Body.String(), private.Error()) {
