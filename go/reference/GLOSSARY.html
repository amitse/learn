Go Glossary

Terms introduced across lessons. Use this as a quick reference while reading Go code.

Modules & Build (Lesson 2)

Term TS Equivalent Meaning
module new npm package / repo A collection of related Go packages declared by a single go.mod file. The module path (e.g. github.com/user/repo) is its globally unique name.
go.mod new package.json The module manifest. Declares module path, minimum Go version, and required dependencies.
go.sum new package-lock.json Cryptographic checksums for all dependencies. Auto-managed — commit it, never edit by hand.
package new directory of files (roughly) The unit of code organization in Go. One directory = one package. Declared with package <name> at the top of every .go file.
go run . new ts-node src/index.ts Compiles and runs the current package immediately. Good for development.
go build . new tsc + node dist/index.js Compiles to a static native binary. No runtime required to execute it.
go get <path> new npm install <pkg> Fetches a dependency and adds it to go.mod / go.sum.
exported identifier new export keyword Any identifier starting with a capital letter is exported (public). Lowercase = package-private. No keyword needed.

Core Language (Lesson 1)

Term TS Equivalent Meaning
struct interface / type A named collection of fields. Go's primary way to model data shapes.
:= const / let + inference Short variable declaration — declares and assigns with type inferred. Only usable inside functions.
error Error / throw Go's built-in interface for errors. Functions return (value, error); callers check if err != nil.
nil null / undefined The zero value for pointers, slices, maps, channels, functions, and interfaces.
defer finally / cleanup Schedules a function call to run when the surrounding function returns. Common for closing files, unlocking mutexes.
