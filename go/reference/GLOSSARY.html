Go Glossary

Terms introduced across lessons. Use this as a quick reference while reading Go code.

Project Layout (Lesson 10) new

Term TS Equivalent Meaning
package module / directory A directory of .go files that share a package declaration. The unit of encapsulation in Go. All files in the same directory are in the same package and can see each other's unexported identifiers.
internal/ (no direct equiv.) A special directory enforced by the Go compiler. Only code within the same module (rooted at the parent of internal/) may import packages from it. Used to keep packages private to your project.
cmd/ src/index.ts (entry) Convention for placing binary entry points. cmd/server/main.go is the HTTP server entry point. Multiple binaries can coexist under cmd/.
pkg/ published npm package Convention for packages intended to be imported by other modules (libraries). For application servers, prefer internal/ unless you intend to publish.
module path @/ path alias The string declared in go.mod (e.g. github.com/amit/myserver). Serves as the root for all import paths within the module. Sub-packages are imported as "module-path/internal/handlers".
go build ./... tsc --build / pnpm build Builds all packages in the module. The ./... wildcard means "this directory and all sub-directories". go test ./... runs all tests likewise.

Testing (Lesson 9)

Term TS Equivalent Meaning
_test.go .test.ts / .spec.ts File naming convention for test files. The Go toolchain discovers them automatically — no config needed. Test functions begin with Test and accept *testing.T.
httptest.NewRecorder() supertest response mock Creates a fake http.ResponseWriter that buffers the status code, headers, and body your handler writes. Read results via .Code and .Body.String().
httptest.NewRequest() supertest request builder Creates a fake *http.Request — no network connection. Pass method, URL, and optional body. Set headers with .Header.Set(...).
t.Errorf(...) expect(...).toBe(...) (soft fail) Marks the test as failed and logs a message, but continues running the rest of the test function. Use when you want to collect all failures.
t.Fatal(...) / t.Fatalf throw / test.fail() (hard fail) Marks failure and stops the test immediately (FailNow). Use when further assertions are meaningless (e.g., bad JSON decode).
t.Run(name, func) it('name', fn) in describe Runs a named sub-test. On failure, Go prints TestFoo/name. Used in table-driven tests to give each case a readable label.
table-driven test test.each / describe+it matrix Go idiom: define a slice of anonymous structs (each row = one case with inputs + expected outputs), loop over them, call t.Run per case. No extra library needed.
go test -cover ./... jest --coverage Runs all tests and prints per-package statement coverage %. Add -coverprofile=c.out then go tool cover -html=c.out for an annotated HTML report.

Error Handling (Lesson 8)

Term TS Equivalent Meaning
error Error (throw/catch) Built-in interface: Error() string. Returned as a second value from functions that can fail. If no error occurred, the value is nil.
errors.New("msg") new Error("msg") Creates a simple static error value. Use for sentinel errors and short messages with no runtime context.
fmt.Errorf("ctx: %w", err) new Error(`ctx: ${err}`) Creates a new error wrapping an existing one. %w preserves the original error inside the chain so errors.Is/errors.As can find it later. Using %v converts it to a string and loses the chain.
sentinel error named error constant Package-level var ErrXxx = errors.New(...). Named with Err prefix. Callers compare against them with errors.Is.
errors.Is(err, target) err === ERR_TARGET Walks the full error chain looking for a value that matches target. Use instead of == when errors may be wrapped.
errors.As(err, &target) err instanceof SomeError Walks the chain looking for an error matching the type of target. If found, fills target and returns true. Use to extract typed fields from custom errors.
custom error type class extends Error Any struct implementing Error() string. Lets you attach structured data (e.g. HTTP status codes) to errors. Extracted in handlers with errors.As.

Integration Patterns (Lesson 7)

Term TS Equivalent Meaning
writeJSON(w, status, data) res.status(n).json(obj) Shared helper: sets Content-Type: application/json, writes status code, encodes data. Prevents repeating header/encoder boilerplate in every handler.
writeError(w, status, msg) res.status(n).json({error}) Shared error helper: always returns {"error":"..."} JSON. Must be followed by return — Go does not stop handler execution automatically.
return (after error write) implicit — res.json() ends chain Explicit early exit in a handler after writing an error response. Without it, execution continues and a second write attempt triggers a "superfluous WriteHeader" warning.
log.Fatal(...) process.exit(1) on throw Calls log.Println then os.Exit(1). Used to wrap http.ListenAndServe so a startup failure (port in use, permission denied) exits loudly rather than returning silently.
any unknown / any (TS) Go 1.18+ alias for interface{}. Accepts any type as a value. Prefer any over interface{} in new code — identical at runtime, cleaner syntax.

JSON (Lesson 5)

Term TS Equivalent Meaning
encoding/json JSON.stringify / parse Standard library package for JSON encoding and decoding. No install needed. Docs: pkg.go.dev/encoding/json
struct tag field rename in serialiser Backtick string on a struct field: `json:"key"`. Controls the JSON key name used during encode/decode. Without a tag, Go uses the exact field name (PascalCase).
json:"key,omitempty" optional field / undefined Omits the field from JSON output when it holds the zero value (empty string, 0, nil, false). Does NOT omit non-zero values.
json:"-" @Exclude() / separate DTO Completely excludes the field from both marshalling and unmarshalling. Use for sensitive fields (passwords, internal tokens).
json.NewDecoder(r.Body).Decode(&v) req.body (via middleware) Streams-decodes the request body JSON into struct v. Must pass a pointer (&v). Always check returned error.
json.NewEncoder(w).Encode(v) res.json(obj) Streams-encodes struct v as JSON directly into the response writer. Set Content-Type: application/json header first.
json.Marshal(v) JSON.stringify(obj) Returns []byte. Use when you need the raw JSON bytes (logging, signing). Prefer NewEncoder for HTTP responses.
json.Unmarshal(b, &v) JSON.parse(str) Decodes []byte into struct v. Use when you already have a byte slice, not a reader.

Routing (Lesson 4)

Term TS Equivalent Meaning
http.NewServeMux() express() / new Router() Creates a fresh, isolated HTTP multiplexer (router). Pass it to ListenAndServe instead of nil.
ServeMux Express Router Go's built-in HTTP request multiplexer. Matches incoming URLs to registered handler functions.
exact pattern app.get('/path', h) A pattern without a trailing slash — matches only that exact URL. E.g. "/users" matches only /users.
subtree pattern app.use('/prefix', …) A pattern with a trailing slash — matches the prefix and any sub-path. E.g. "/api/" matches /api/v1/users.
{name} wildcard :name in Express A path parameter in a Go 1.22+ mux pattern. E.g. "GET /users/{id}". Extract with r.PathValue("id").
r.PathValue(name) req.params.name Reads a named path wildcard from the matched pattern. Returns empty string if not found.
http.Error(w, msg, code) res.status(code).send(msg) Convenience function that writes a plain-text error body and sets the given HTTP status code.

HTTP Server (Lesson 3)

Term TS Equivalent Meaning
net/http express (sort of) Standard library package providing HTTP client and server primitives. No install needed.
http.ResponseWriter res (Express) Interface passed to every handler. Write status, headers, and body through it. Headers must be set before body.
*http.Request req (Express) Pointer to a struct containing the full incoming request: Method, URL, Header, Body, etc.
http.HandleFunc app.get / app.post Registers a handler function on the DefaultServeMux for a given path pattern.
http.ListenAndServe app.listen Starts the HTTP server. Second arg is the handler/mux; nil uses DefaultServeMux.
DefaultServeMux the default Express app The global default router. http.HandleFunc registers on it; passing nil to ListenAndServe uses it.
w.WriteHeader(code) res.status(code) Sends the HTTP status code. Must be called before writing the body — cannot be changed after.
w.Header().Set(k,v) res.set(k, v) Sets a response header. Must be called before WriteHeader or first body write.
r.URL.Path req.path The URL path string of the request, e.g. "/users/42".
r.Method req.method The HTTP verb as a string: "GET", "POST", "DELETE", etc.

Modules & Build (Lesson 2)

Term TS Equivalent Meaning
module npm package / repo A collection of related Go packages declared by a single go.mod file. The module path (e.g. github.com/user/repo) is its globally unique name.
go.mod package.json The module manifest. Declares module path, minimum Go version, and required dependencies.
go.sum package-lock.json Cryptographic checksums for all dependencies. Auto-managed — commit it, never edit by hand.
package directory of files (roughly) The unit of code organization in Go. One directory = one package. Declared with package <name> at the top of every .go file.
go run . ts-node src/index.ts Compiles and runs the current package immediately. Good for development.
go build . tsc + node dist/index.js Compiles to a static native binary. No runtime required to execute it.
go get <path> npm install <pkg> Fetches a dependency and adds it to go.mod / go.sum.
exported identifier export keyword Any identifier starting with a capital letter is exported (public). Lowercase = package-private. No keyword needed.

Middleware (Lesson 6)

Term TS Equivalent Meaning
middleware Express middleware A function with signature func(next http.Handler) http.Handler. Wraps a handler to run code before/after it. No global registry — compose by nesting.
http.Handler RequestHandler type An interface with one method: ServeHTTP(ResponseWriter, *Request). Any type implementing that method is an http.Handler.
http.HandlerFunc (type adapter) A named function type that satisfies http.Handler. Converts a plain func(w, r) into an http.Handler so it can be passed to mux.Handle or used in middleware chains.
next.ServeHTTP(w, r) next() in Express Calls the wrapped/next handler in the middleware chain. Explicit — you must call it yourself; forgetting it short-circuits the chain.
mux.Handle(pattern, h) app.use(path, h) Registers an http.Handler (not a plain function) on the mux for a given path. Use http.HandlerFunc(fn) to convert a plain function.
handler := A(B(mux)) app.use(A); app.use(B) Middleware chaining by nesting. A is outermost — runs first on request, last on response. Order matters.

Core Language (Lesson 1)

Term TS Equivalent Meaning
struct interface / type A named collection of fields. Go's primary way to model data shapes.
:= const / let + inference Short variable declaration — declares and assigns with type inferred. Only usable inside functions.
error Error / throw Go's built-in interface for errors. Functions return (value, error); callers check if err != nil.
nil null / undefined The zero value for pointers, slices, maps, channels, functions, and interfaces.
defer finally / cleanup Schedules a function call to run when the surrounding function returns. Common for closing files, unlocking mutexes.
