# Go Resources

## Knowledge

- [A Tour of Go](https://go.dev/tour/)
  The official interactive Go tutorial. Use for: verifying syntax, trying snippets, quick reference on any language feature.

- [Go by Example](https://gobyexample.com/)
  Annotated examples for every major Go construct. Use for: "how do I do X in Go" reference — closest thing to a Go cookbook.

- [Effective Go](https://go.dev/doc/effective_go)
  Official idioms and style guide. Use for: understanding why Go code looks the way it does, after the basics are in.

- [net/http — Go Standard Library](https://pkg.go.dev/net/http)
  The stdlib HTTP package used in every lesson. Use for: handler signatures, request/response types, routing.

- [JSON and Go — The Go Blog](https://go.dev/blog/json)
  Canonical guide to encoding/json. Use for: marshalling/unmarshalling, struct tags, error handling with JSON.

## Wisdom (Communities)

- [r/golang](https://reddit.com/r/golang)
  Active, beginner-friendly. Good for "is this idiomatic?" questions.

- [Gophers Slack](https://invite.slack.golangbridge.org/)
  #beginners channel is patient and fast. Best place for live troubleshooting.
