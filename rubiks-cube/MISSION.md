# Mission: Rubik's Cube

## Why
I want to be able to solve a standard 3×3 Rubik's Cube from any scrambled state.
The goal is a complete, repeatable solve — not memorising one lucky sequence, but
understanding the method well enough to execute it reliably every time.

## Success looks like
- Can solve a fully scrambled 3×3 cube from start to finish without help
- Understands each stage of the beginner's layer-by-layer method
- Can recover when a step goes wrong, rather than restarting from scratch
- Target: first unaided solve within 30 days

## Constraints
- Learning happens in short daily sessions (Telegram + browser)
- No physical cube required for understanding — but practice on a real or virtual cube expected
- Prefer visual, interactive lessons over text walls

## Out of scope
- Speed cubing (sub-60s times) — not the goal right now
- Advanced methods (CFOP, Roux, ZZ) — save for after first solve
- Other puzzle types (4×4, pyraminx) — out of scope for this workspace
