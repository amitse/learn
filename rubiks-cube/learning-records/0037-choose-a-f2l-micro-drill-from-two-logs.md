# 0037 — Choose an F2L Micro-Drill from Two Logs

**Date:** 2026-08-26  
**Lesson:** `0037-choose-a-f2l-micro-drill-from-two-logs.html`

## What was taught

- Two F2L observation logs can select a single targeted micro-drill when their earliest mismatch repeats.
- A repeated mismatch before destination positions is a planning target (pair, slot, side, or named setup); a repeated mismatch after destination positions but before a trigger is a green-light target; a repeated mismatch after a verified green light and trigger is an execution/hold target.
- The selected drill is five controlled repetitions of only that stage, rather than a full solve or repeated trigger guesses.

## Key non-obvious insights

- A destination picture proves that planning reached the intended locations; it does not prove corner orientation or edge readiness, so it should not be labelled an execution error.
- When the two attempts show different labels, the earlier workflow failure is the more useful practice target because later observations depend on it.
- A micro-drill preserves the mission’s recovery focus: it creates clear evidence without disrupting protected pairs through uncontrolled exploration.

## Zone of proximal development — next

**F2L: use a three-attempt evidence set to decide whether a micro-drill worked.** Compare first mismatches before and after five controlled repetitions, retain the drill only when the repeated earliest mismatch changes or disappears.
