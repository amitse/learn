# 0039 — Write a Precise F2L Micro-Drill

**Date:** 2026-08-30  
**Lesson:** `0039-write-a-precise-f2l-micro-drill.html`

## What was taught

- A three-log assessment becomes actionable as a four-part F2L micro-drill specification: comparable condition, five-repetition boundary, observable checkpoint, and retain/change decision rule.
- The drill targets only the current earliest mismatch: planning, green-light recognition, or authorized-trigger execution.
- After five repetitions, one fresh comparable log retains the drill only when the first mismatch disappears or moves later; the same earliest mismatch calls for one refinement or a slower read.

## Key non-obvious insights

- A later mismatch is evidence that the former bottleneck improved, but it defines the next narrow drill rather than justifying an unfocused full-solve practice session.
- The checkpoint must sit at the boundary of the selected stage: a green-light drill stops before the trigger, so it does not accidentally practise execution instead.
- Writing the condition before turning protects the mission’s recovery focus by limiting changes to a known pair and empty workspace.

## Zone of proximal development — next

**F2L: compare two drill specifications and select the one with a testable checkpoint.** Distinguish a bounded, evidence-producing drill from a broad practice intention, then refine one missing element without changing the target bottleneck.
