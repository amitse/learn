# 0046 — Run a Five-Repetition Successor Drill

**Date:** 2026-09-13  
**Lesson:** `0046-run-a-five-repetition-successor-drill.html`

## What was taught

- A five-repetition successor run holds an audited F2L specification fixed: target pair, empty workspace, retained cue, authorized trigger, and one checkpoint.
- Each repetition is logged immediately at the checkpoint as an observable result; an individual miss does not justify changing the remaining repetitions.
- A row is invalid when the fixed condition or checkpoint was lost. Five checkpoint rows are evidence only; Fresh E/F are collected afterward before making a verdict.

## Key non-obvious insights

- Changing the setup or cue after an early miss destroys the comparison, even if later attempts succeed.
- “Not placed after the trigger” is useful evidence; it need not be explained during the run.
- Invalidity concerns comparability, not success: a valid miss remains in the log, while an unlike attempt must not be silently counted.
