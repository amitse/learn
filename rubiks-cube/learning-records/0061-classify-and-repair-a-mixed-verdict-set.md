# 0061 — Classify and Repair a Mixed Verdict Set

**Date:** 2026-10-13  
**Lesson:** `0061-classify-and-repair-a-mixed-verdict-set.html`

## What was taught

- Triage each Fresh E/F verdict independently using the fixed first-failure order: condition, evidence, then action.
- Classify any drift in target pair, empty workspace type, retained cue (including timing), or checkpoint as **FRESH EVIDENCE** and write a matching replacement-attempt plan rather than changing practice.
- For comparable attempts, repair only an invented evidence cause or an unsupported/duplicated action; an all-passing row is **ACT**.

## Key non-obvious insights

- Identical-looking first-mismatch labels do not make two logs comparable when even one condition field differs.
- A mixed set can contain an action-ready row and an evidence-needed row at the same time; each verdict keeps its own evidence boundary.
- Minimal repair protects useful observations: delete the first unsupported story or extra action instead of changing pair, workspace, algorithm, or drill.
