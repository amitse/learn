# 0065 — Write One Mixed-Card Queue Instruction

**Date:** 2026-10-22  
**Lesson:** `0065-write-one-mixed-card-queue-instruction.html`

## What was taught

- Turn one selected row of an audited mixed F2L triage card into exactly one verb-led queue instruction.
- Preserve the row’s classification: an **ACT** row authorizes its one evidence-matched practice action; a **FRESH EVIDENCE** row authorizes only a matching replacement attempt.
- Keep the four comparison fields—target pair, empty workspace type, retained cue, and checkpoint—together when collecting replacement evidence.

## Key non-obvious insights

- A queue instruction is scoped to one row; an apparently relevant action on another row cannot be appended to it.
- FRESH EVIDENCE is an instruction to restore comparability, not permission to infer a cause or change a drill.
- One action per line protects attribution: the resulting observation can be connected to the chosen condition and action.

## Zone of proximal development — next

**F2L: audit one written queue instruction.** Given an audited card row and a proposed one-line instruction, confirm that it preserves the correct classification and conditions, contains one permitted action, and imports nothing from another row.
