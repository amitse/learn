# 0044 — Write the Next F2L Micro-Drill

**Date:** 2026-09-09  
**Lesson:** `0044-write-the-next-f2l-micro-drill.html`

## What was taught

- A completed refined-drill verdict becomes a successor micro-drill only by retaining the proven cue, isolating one shared later first mismatch, and preserving the original comparable condition.
- A testable successor specification names the pair, empty workspace type, retained cue, one later-stage checkpoint, five controlled repetitions, and two matching fresh logs.
- When either fresh log repeats the original earliest mismatch, the next drill remains at that old stage with one minimal refinement; condition drift requires evidence repair, not a new drill.

## Key non-obvious insights

- A cue that cleared the old bottleneck in both fresh logs is part of the controlled condition, not a variable to remove while testing the later bottleneck.
- “Practice F2L” is not a testable drill: an observable checkpoint and a one-stage boundary make a later verdict interpretable.
- A later stage becomes the target only when it is the shared first mismatch in both comparable fresh logs.
