# 0030 — F2L: Name the U Setup

**Date:** 2026-08-12  
**Lesson:** `0030-name-the-f2l-u-setup.html`

## What was taught

- After the Lesson 29 position filter identifies a viable pair, each right- or left-side position row maps to one exact setup: `0`, `U`, `U2`, or `U′`.
- The learner can name that one move before turning, carrying the pair to the side’s destination picture (`UFR + UF` for right; `UFL + UF` for left).
- `0` is an intentional setup choice: when the destination already exists, no U move is needed.
- Arriving at destination positions still requires the two-part green light—corner white direction plus edge-front-sticker/centre match—before the F2L trigger.

## Key non-obvious insights

- A viable template does more than permit a four-state scan: it determines one planned setup, eliminating exploratory U cycling.
- Positioning and authorization remain separate; an exact named setup can be correct while the pair orientation remains unsafe for insertion.
- Saying the move before acting creates a compact feedback loop: expected destination → one turn → visual verification.

## Zone of proximal development — next

**F2L: diagnose a failed green light after a correctly named setup.** Distinguish a positional success from an orientation failure and select the safe response—stop and normalize/re-read rather than forcing the trigger.
