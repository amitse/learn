## What was taught

- **The 5 core algorithms** reviewed with full move sequences: Sune, Anti-Sune, Y-Perm, Ua-Perm, Ub-Perm
- **Algorithm tagging**: each algorithm mapped to its phase (OLL vs PLL) and use case
- **Finger hints** provided for each algorithm to bootstrap muscle memory
- **Drill timer**: per-algorithm timed reps with automatic fast/slow classification and session rep counter
- **Recognition quiz**: 5 scenario-based questions testing when to apply each algorithm, with instant feedback

## Key non-obvious insights

- **Accuracy before speed**: fluency degrades under pressure if speed is prioritised too early — slow, correct reps build better muscle memory than fast, error-prone ones
- **Sune may be applied 2–3 times** in a row for some OLL cases — this is expected, not a mistake
- **Anti-Sune is the "contrast" algorithm to Sune** — learning them back-to-back helps the hands feel the difference
- **Y-Perm's first half ends at F'** — treating it as two chunks reduces cognitive load significantly
- **Ua and Ub are mirrors**: learning Ua's rhythm makes Ub feel like the reverse

## Zone of proximal development — next

- **OLL case recognition**: identify specific OLL cases by sticker pattern (dot, L-shape, line, cross, Sune/Anti-Sune) to pick the right algorithm instantly without trial-and-error
- **Consistent sub-3-minute solves**: once algorithms are fluent, focus on reducing hesitation between steps
- **Look-ahead during white cross / F2L**: start scanning for the next piece while executing the current algorithm
