# 0015 — First Timed Solve

**Date:** 2026-07-12
**Lesson:** `0015-first-timed-solve.html`

## What was taught

- **Full method recap**: all 7 steps of the beginner CFOP solve presented in one reference panel
- **Quick algorithm table**: all 9 key algorithms (Right Trigger, F2L Right/Left, Cross, Sune, Anti-Sune, Y-Perm, Ua, Ub) in one place
- **Built-in scramble generator**: 20-move random scramble for each practice attempt
- **Built-in solve timer**: start/stop/lap tracking with best time and average across multiple solves
- **Solve strategy tips**: concrete guidance for each stage transition (slow down at step boundaries, use y rotations not U turns during PLL, etc.)

## Key non-obvious insights

- First solve goal is **completion, not speed** — even 10+ minutes is a valid first benchmark
- The diagonal corner swap in PLL is NOT an error — it requires 2 Y-Perm executions and is a known expected case
- During PLL, U-layer turns break the orientation established by OLL; always use whole-cube y rotations
- The dot case (no cross, no line) for OLL requires up to 3 applications of F R U R' U' F' — not a different algorithm
- Having all algorithms on a single reference panel during the first solve is expected and encouraged

## Zone of proximal development — next

- **Sub-5-minute target**: once first complete solve is done, the next milestone is consistency (3 solves in a row without getting stuck)
- **Algorithm fluency**: isolate and drill each of the 5 "key" algorithms (Sune, Anti-Sune, Y-Perm, Ua, Ub) for finger-muscle memory
- **OLL case recognition**: learn to identify Sune vs Anti-Sune by sticker pattern rather than trial-and-error
- **Look-ahead introduction**: begin looking ahead during white cross to set up F2L
