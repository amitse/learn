# 0053 — Audit a Matching Fresh E/F Plan

**Date:** 2026-09-27
**Lesson:** `0053-audit-a-matching-fresh-e-f-plan.html`

## What was taught

- A written matching Fresh E/F collection plan is ready only when both lines retain the same target pair, empty working-slot type, retained cue, and observation checkpoint.
- An audit compares those four fields directly before turning; similar wording does not compensate for a changed condition.
- When one field drifts, repair only that field by copying the baseline value, then collect the matching replacement evidence.

## Key non-obvious insights

- Timing is part of a retained cue: using the same words only after a setup move is condition drift when the cue is meant to begin the attempt.
- A changed checkpoint changes what is observed, even when pair, workspace, and cue remain fixed.
- Minimal repair preserves the controlled comparison; changing several fields to make an attempt easier loses the evidence basis.
