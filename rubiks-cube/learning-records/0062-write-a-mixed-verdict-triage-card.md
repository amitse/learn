# 0062 — Write a Mixed-Verdict Triage Card

**Date:** 2026-10-15  
**Lesson:** `0062-write-a-mixed-verdict-triage-card.html`

## What was taught

- Turn each row in a mixed F2L Fresh E/F set into a complete triage-card line: classification, literal condition/evidence note, and exactly one next instruction.
- Use the fixed audit order—condition, evidence, action—independently for every row; do not form a set-level conclusion.
- Write **ACT** rows as one evidence-matched practice instruction, and write **FRESH EVIDENCE** rows as a matching replacement-attempt instruction with the drifted field restored.

## Key non-obvious insights

- A mixed set is a queue of independent decisions, not a vote: a valid ACT row never authorizes practice changes for a drifted row.
- The card’s classification comes before prose, which makes condition drift visible before an attractive explanation can influence the next drill.
- A replacement-attempt instruction is the whole next action for FRESH EVIDENCE; it must not append a new drill, algorithm, or cause.

## Zone of proximal development — next

**F2L: audit a completed mixed-verdict triage card.** Given several completed card lines, identify the first row whose classification, literal note, or next instruction violates the condition → evidence → action order and minimally repair that row.
