# 0058 — Classify One Repaired Fresh E/F Verdict

**Date:** 2026-10-07  
**Lesson:** `0058-classify-one-repaired-fresh-e-f-verdict.html`

## What was taught

- Classify a minimally repaired Fresh E/F verdict as **ACT** only when its condition, evidence, and single action all pass the ordered gate.
- Classify it as **FRESH EVIDENCE** when any of the four condition fields drifted, even if the repair accurately asks for a replacement attempt.
- Keep the classification separate from the repair: a well-written replacement plan is not yet permission to change a drill.

## Key non-obvious insights

- An actionable-looking sentence is not action-ready unless the underlying Fresh E/F attempts are comparable.
- The gate is ordered: condition failure ends interpretation; evidence and action cannot compensate for drift.
- Exactly one evidence-matched action is required for ACT; multiple plausible actions are still an audit failure.
