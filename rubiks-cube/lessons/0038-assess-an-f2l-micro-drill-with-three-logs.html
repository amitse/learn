Assess one F2L micro-drill with three logs

A micro-drill earns another session only when the next comparable attempt shows that the earliest bottleneck moved or disappeared.

The one thing to learn

Lesson 37 used two logs to choose

Retention rule: after five controlled reps, retain the drill only if attempt 3’s first mismatch changes to a later stage or disappears. If the same earliest mismatch remains, do not call it fixed—adjust the drill or take a fresh, slower read.

Read one three-log set

Baseline A
First mismatch: named U setup does not reach UFR + UF.
Label: planning.
Baseline B
First mismatch: named U setup does not reach UFR + UF.
Label: planning.

Run five repetitions of only the plan → setup → position-check stage. Then make one comparable attempt:

Check C
Setup reaches UFR + UF; corner white faces Up.
First mismatch: green light.

That is progress. Planning is no longer the earliest mismatch; a later, more specific green-light issue is now visible. Retain the planning drill as improved, then choose the next drill from the new evidence.

Do the assessment

  1. Keep Baseline A and B—do not rewrite them after practice.
  2. Perform exactly five focused reps of the selected stage.
  3. Make one fresh comparable attempt and log its first mismatch.
  4. Compare Check C with the repeated baseline label: later/different or none = improved; same = not yet demonstrated.

A later mismatch is not a failure. It means your practice uncovered the next safe thing to work on, without guessing or restarting.
