Rubik's Cube · Lesson 76 · under 10 minutes

Audit one fresh action-ready queue decision

Before you touch the cube, test a newly written decision against its actual checkpoint log and ACT row. Find the first failure—then repair only that.

Today’s one skill

Audit a fresh queue decision in one fixed order: literal evidence → copied permission → four-field scope → exactly one action. It is ACTION-READY only if every gate passes.

The source facts

Valid checkpoint log
Rep 3 — immediately before trigger: corner white faces Right; matching edge’s front sticker matches the front centre.
Selected ACT row
Run five slow green-light reads.
Required scope
blue-red pair · front-right empty slot · say “white right; edge matches front centre” before trigger · checkpoint immediately before trigger

Run the four gates in order

Evidence: Does the decision report only what was visible in the log? “Smooth,” “rushed,” and “ready” are conclusions—not observations.
Permission: Is its action copied exactly from the ACT row? The log does not authorize an insertion or a new drill.
Scope: Does it retain the pair, empty workspace, cue and timing, and checkpoint?
One action: Does it stop after the one permitted drill? A helpful-looking “then insert” still fails.

Stop at the first failed gate. Later correct wording cannot make an earlier failure safe.

Audit this fresh decision

“Because Rep 3 showed white facing Right and the edge matching the front centre immediately before trigger, run five slow green-light reads for the blue-red pair in a front-right empty slot, saying ‘white right; edge matches front centre’ before trigger, then insert the pair.”

Gate 1 passes: the evidence is literal. Gate 2 passes: the five reads are copied from the ACT row. Gate 3 passes: all four scope fields match. Gate 4 fails: “then insert the pair” is a second action.

Minimal repair: delete only “then insert the pair.” The remaining sentence is ACTION-READY.

Quick check

A decision says: “Because Rep 3 was smooth, run five slow green-light reads for the blue-red pair in a front-right empty slot, saying the cue before trigger.” What is the first failed audit gate?

Do it now

Take one decision you wrote after a queue checkpoint. Put its log and ACT row beside it. Say the four gates aloud, stopping at the first mismatch; make one minimal text repair, then begin the audit again from gate 1. Ask your teacher to audit a borderline decision with you.
