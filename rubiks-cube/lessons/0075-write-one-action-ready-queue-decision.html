Rubik's Cube · Lesson 75 · under 10 minutes

Write one action-ready queue decision

Turn one valid F2L checkpoint log and one ACT row into a sentence you can safely execute—without inventing evidence or smuggling in a second action.

Today’s one skill

Write one ACTION-READY bounded queue decision. It gives you a repeatable bridge from what you literally saw on the cube to one permitted next step.

Use this four-part assembly

1 · Evidence: “Because [literal observation] at [checkpoint]…”
2 · Permission: “…[copy the ACT-row action]…”
3 · Scope: “…for [pair] in [workspace], [cue/timing], at [checkpoint]…”
4 · Boundary: Stop. The copied ACT action is the only action.

A valid log supplies observation. The ACT row supplies permission. Neither source lets you add a diagnosis, outcome, or follow-up move.

Source facts — copy, don’t improve

Valid checkpoint log
Rep 2 — immediately before trigger: corner white faces Right; matching edge’s front sticker matches the front centre.
Selected ACT row
Run five slow green-light reads.
Carried scope
blue-red pair · front-right empty slot · say “white right; edge matches front centre” before trigger · checkpoint immediately before trigger

Assemble the decision

Write the four parts in order:

“Because Rep 2 showed white facing Right and the edge matching the front centre immediately before trigger, run five slow green-light reads for the blue-red pair in a front-right empty slot, saying ‘white right; edge matches front centre’ before trigger.”

It is action-ready because every word is traceable: the observation to the log, the drill to the ACT row, and the four scope fields to the source. It ends after the one authorized drill.

One tempting but invalid addition

Not action-ready: “…run five slow green-light reads … then insert the pair.”

Then insert the pair may sound productive, but it is a second action. Delete it; do not rewrite the evidence or scope. The completed sentence above is enough to authorize its single drill.

Do it now

Use a real valid checkpoint log and its selected ACT row. Write one sentence with the four-part assembly, then check it in order: literal evidence → copied permission → all four scope fields → one action. If any check fails, repair only the first failed clause and audit again. Ask your teacher to check a borderline sentence.
