Rubik's Cube · Lesson 74 · under 10 minutes

Classify one audited bounded queue decision

After auditing a decision, give it one honest status: it is ready for its one cube-side action, or it needs the smallest repair first.

Today’s one skill

Classify an audited F2L queue decision as ACTION-READY or MINIMAL REPAIR NEEDED. This protects your F2L practice from acting on a decision that looks polished but still changes evidence, permission, scope, or the one-action boundary.

The classification gate

Lesson 73 gave the audit order. Use its result—not a general impression:

1
All four checks pass: literal checkpoint evidence → copied ACT-row permission → four-field scope → exactly one action. Label it ACTION-READY. Perform that one action.
2
Any check fails: label it MINIMAL REPAIR NEEDED. Repair only the first failed clause, then audit again. Do not execute it yet.

A classification is not a new diagnosis of the cube. It says only whether this written decision is safe to use.

Source facts

ACT row: Run five slow green-light reads.
Scope: blue-red pair · front-right empty slot · say “white right; edge matches front centre” before trigger · checkpoint immediately before trigger.
Valid checkpoint log:
Rep 4 — immediately before trigger: corner white faces Right; matching edge’s front sticker matches the front centre.

Work one decision

Audited candidate: “Because Rep 4 showed white facing Right and the edge matching the front centre immediately before trigger, run five slow green-light reads for the blue-red pair in a front-right empty slot, saying the cue before trigger, then insert the pair.”

Evidence, permission, and scope match. The first failure is the fourth check: the added insertion is a second action. Therefore the correct classification is MINIMAL REPAIR NEEDED.

Minimal repair: delete only then insert the pair. Re-audit the shortened sentence. It now has literal evidence, copied permission, matching scope, and exactly one action—so it is ACTION-READY.

Do not over-repair

Once the first failure is found, preserve every earlier passing clause. Do not change the blue-red pair, replace the log’s observation with “successful,” or add a reason such as “the grip was bad.” Those changes turn a small writing repair into a new unsupported claim.

Quick check

Using the same source facts, which decision is ACTION-READY?

Do it now

Take one decision you audited in Lesson 73. If all four checks pass, write ACTION-READY beside it and perform only its permitted action. If not, write MINIMAL REPAIR NEEDED, fix the first failure only, and re-audit. Ask your teacher to check a borderline sentence.
