Rubik’s Cube · under 10 minutes

Classify a completed refined-drill cycle

After four comparable logs, choose exactly one honest next action: retain, refine once, or move to the newly visible bottleneck.

The one thing to learn

A completed refined-drill cycle contains two baseline logs and two fresh logs under the same pair, empty workspace type, and observation checkpoint. Classify the cycle by the first mismatch in both fresh logs—not by whether a solve happened to feel good.

Decision rule: both fresh logs later or clear → retain; either fresh log repeats the old earliest mismatch → one further refinement; both fresh logs expose the same later first mismatch → start one new, narrow drill at that later stage.

Read the evidence, not the outcome

All four examples below use blue-red, an empty front-right slot, and the green-light checkpoint. The refined cue is: “front sticker, front centre.” Baselines A and B first failed the edge-centre check.

The cue improved the old recognition bottleneck in both logs. Retain it—but do not widen its drill. The new shared first mismatch is an execution/hold target, so write a separate, bounded drill for that later stage.

Three verdicts

  1. Retain: Fresh C and D both remove or move past the old mismatch, and do not show one shared later bottleneck yet. Keep the refinement as part of your read.
  2. Refine once: C or D still first fails the original edge-centre check. Conditions matched, so the evidence says that cue has not reliably fixed the target. Change one cue or pace only, then collect two fresh logs.
  3. New later-stage drill: C and D both move past the old mismatch and first fail at the same later stage. The original refinement worked; preserve it and target only the later stage next.

A later mismatch is progress evidence. It is not a reason to discard the successful cue or return to uncontrolled full solves.

Your 4-minute action

  1. Write the baseline’s pair, workspace, checkpoint, and earliest mismatch.
  2. Check that Fresh C and D match all three conditions. If not, the cycle is inconclusive: repair evidence before a verdict.
  3. For each fresh log, underline its first mismatch.
  4. Compare it with the baseline mismatch. Write one verdict: retain, refine once, or new later-stage drill.
  5. If a later stage repeats twice, name only that stage’s checkpoint for tomorrow’s drill. Keep today’s successful cue.
