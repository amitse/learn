Rubik’s Cube · F2L evidence practice

Audit a mixed-verdict triage card

Find the first bad card line, repair only that line, and keep the next F2L practice action evidence-bound.

⏱ 7–9 minutes · One skill: audit one completed triage-card line

The card is only useful if every line passes

Lesson 62 turned each Fresh E/F row into a card line. Today, read the finished line in the same order used to create it:

1
Classification. Does ACT mean all four condition fields match? Does FRESH EVIDENCE name actual drift?
2
Literal note. Does the note copy the condition drift or recorded first mismatch—without an invented cause?
3
One instruction. Is there exactly one action that follows from that classification?

Stop at the first failure. Repair that clause or line only; do not rewrite clean rows or add a new cube theory.

Two repair patterns

Condition drift
E: cue before setup · F: cue after setup

Bad: ACT → both missed destination positions → slow the setup drill.

Repair: FRESH EVIDENCE → cue timing drifted → collect F with cue before setup.

The first failure is condition, so the mismatch and drill action cannot be interpreted yet.

Comparable attempts, bad action
All four fields match. Both first miss: edge-centre check.

Bad: ACT → both first miss edge-centre check → slow recognition and change trigger.

Repair: ACT → both first miss edge-centre check → slow the edge-centre recognition drill.

Keep the valid classification and literal evidence; remove the unsupported second action.

Audit a three-line card

Read A, then B, then C. The first failing line is the one to repair.

A
ACT → both first miss destination positions → slow the named-U-setup planning drill.
Fields match; both logs record destination positions missed.
B
ACT → both first miss edge-centre check → slow recognition.
Fresh E used an empty front-right workspace; Fresh F used empty front-left.
C
ACT → both first miss post-trigger placement → slow the authorized-trigger execution drill.
Fields match; both logs record post-trigger placement missed.

The answer is B: its workspace drift means it must become a replacement-evidence line. A and C are not permission to overlook B.

B → FRESH EVIDENCE → workspace drifted → collect Fresh F with empty front-right workspace.

Quiz 1: name the first failed check

A card line says ACT → both first miss destination positions → slow planning. The target pair, workspace, cue, and checkpoint all match—but Fresh F actually records edge-centre check failed. What fails first?

Quiz 2: choose the minimal repair

Fresh E/F share all four fields and both record destination positions missed. The card says: ACT → bad look-ahead caused missed positions → slow planning and switch to a left trigger.

2-minute cube-side task

  1. Take one triage card you wrote (or invent two Fresh E/F rows).
  2. Cover the verdict, then compare the four condition fields.
  3. Reveal the card line and check classification → literal note → one instruction.
  4. If something fails, change only the earliest failing part. If condition drifted, write a replacement-attempt instruction instead.

Ask your teacher to check a card line if you cannot tell whether an explanation is an observation or an invented cause.
