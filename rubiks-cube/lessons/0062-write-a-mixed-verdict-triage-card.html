Rubik’s Cube · F2L evidence practice

Write a mixed-verdict triage card

Turn several F2L verdict rows into a usable next-step card—without letting a clean row hide drift in another one.

⏱ 7–9 minutes · One skill: write one complete, row-local triage card

The card has one line per row

A triage card is not a new cube algorithm. It is a compact record that prevents an unsupported drill change after several F2L attempts.

Row [name] → [ACT or FRESH EVIDENCE] → [one literal evidence/condition note] → [one next instruction]
ACT
All four condition fields match; the evidence is literal; one action follows. Write the repaired verdict as the instruction.
FRESH EVIDENCE
A condition field drifted. Write the one-line matching replacement-attempt plan—not a drill change.

Never make a set-level verdict. Complete one row before moving to the next.

Build it in this fixed order

  1. Condition: compare target pair, empty workspace type, retained cue including timing, and checkpoint.
  2. Evidence: if conditions match, copy the recorded first mismatch—no “because I rushed” story.
  3. Action: keep exactly one action. If the row fails condition, stop: collect a matching replacement attempt.

The actual F2L skill remains centre-defined pair recognition, setup, and insertion; this card simply keeps practice decisions tied to observations.

Worked card: three independent rows

A
E/F: blue-red; empty front-right; cue before setup; pre-trigger. Both: edge-centre check fails.
Card: A → ACT → both first miss edge-centre check → slow the edge-centre recognition drill.
B
E: blue-red; empty front-right; cue before setup; pre-trigger. F: blue-red; empty front-left; cue before setup; pre-trigger.
Card: B → FRESH EVIDENCE → workspace drifted → collect F with empty front-right, cue before setup, at pre-trigger checkpoint.
C
All four fields match. Both: destination positions missed. Draft says “bad grip; slow planning and switch triggers.”
Card: C → ACT → both first miss destination positions → slow the named-U-setup planning drill.
“Bad grip” and the trigger switch are deleted: neither is supported, and the draft had two actions.

Quiz 1: choose the correct card line

Fresh E and F match on pair, workspace, cue, and checkpoint. Both record “first mismatch: destination positions missed.” Which line is valid?

Quiz 2: finish this card

In Row D, the pair and workspace match, but Fresh E uses the retained cue before setup and Fresh F uses it after setup. Choose the next instruction.

2-minute cube-side task

  1. Copy three current Fresh E/F rows onto paper or notes.
  2. Under each, write ACT or FRESH EVIDENCE first.
  3. Complete exactly one card line using the template. For FRESH EVIDENCE, copy the baseline values into the replacement instruction.
  4. Only act on an ACT row. Collect evidence for the others.

Ask your teacher to review your card if a row seems to need two actions. It almost always needs one narrower instruction first.
