Rubik's Cube · Lesson 73 · under 10 minutes

Audit one bounded queue decision

Before acting on a decision, test that it preserves literal evidence, copied permission, all four scope fields, and one action.

Today’s one skill

Find the first failure in a queue decision, then repair only that failure. This keeps F2L practice interpretable: one cube observation supports one authorized next step—not a story or a chain of turns.

The source facts

ACT source row
Approved action: run five slow green-light reads.
Scope: blue-red pair · front-right empty slot · say “white right; edge matches front centre” before trigger · checkpoint immediately before trigger.
VALID CHECKPOINT LOG
Rep 4 — immediately before trigger: front-right slot empty; corner white faces Right; matching edge’s front sticker matches the front centre.

These are the only permissions available to the decision. The log provides a visible observation; the ACT row provides one action.

The audit order: E → P → S → 1

1
Evidence: Does the “Because” clause quote the visible checkpoint observation—without “successful,” “rushed,” or a cause?
2
Permission: Is the action copied from the selected ACT source row, rather than newly invented?
3
Scope: Are the blue-red pair, front-right empty slot, cue before trigger, and immediate-before-trigger checkpoint preserved?
4
One action: Does the decision stop after the single approved action? “Then …” is a warning light.

Stop at the first failure. A later correct clause does not repair it.

Audit this candidate

Candidate: “Because Rep 4 showed white facing Right and the edge matching the front centre, run five slow green-light reads for the blue-red pair in a front-left empty slot, using the cue before trigger.”

Pass: literal evidence and copied action. First failure: scope—the source requires a front-right empty slot. The smallest repair is to replace front-left with front-right. Do not rewrite the evidence or add another drill.

Repaired decision: “Because Rep 4 showed white facing Right and the edge matching the front centre, run five slow green-light reads for the blue-red pair in a front-right empty slot, using the cue before trigger.”

What not to repair

Do not write: “Because Rep 4 was successful, run five slow green-light reads, then insert faster.”
  • successful is a conclusion, not the literal checkpoint observation;
  • then insert faster is a second action; and
  • changing both issues at once would hide which audit check failed first.

Repair the evidence first: restore the literal observation. On a new audit pass, remove the extra action.

Quick check

Using the source facts above, which candidate passes the complete audit?

Do it now

Put one Lesson 72 decision beside its ACT row and valid checkpoint log. Audit it in the order evidence → permission → scope → one action. If it fails, change only the first failed clause; then audit it again. Ask your teacher to check a sentence if the action seems copied but you are unsure.
