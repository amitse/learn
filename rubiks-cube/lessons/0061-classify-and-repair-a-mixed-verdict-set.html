Rubik’s Cube · F2L evidence practice

Classify and repair a mixed verdict set

When several F2L conclusions look plausible, do not choose by confidence. Give each one its first-failure classification, then make only the repair that classification permits.

⏱ 7–9 minutes · One skill: triage several Fresh E/F verdicts without mixing their repairs

The three possible first-failure outcomes

CONDITION
Any of the four fields drifted: pair, empty workspace type, retained cue/timing, or checkpoint.
Classify: FRESH EVIDENCE.
EVIDENCE
Conditions match, but the written mismatch adds or changes what the logs say.
Repair: literal evidence clause.
ACTION
Condition and evidence match, but the conclusion overreaches or contains two actions.
Repair: one matched action.

Classify each verdict independently. A valid ACT in one row never makes a drifted row comparable.

Worked mixed set

A · drifted condition
E: blue-red · empty front-right · cue before setup · pre-trigger
F: blue-red · empty front-left · cue before setup · pre-trigger
Draft: “Both first fail edge-centre; slow recognition.”
First failure: workspace differs. Classification: FRESH EVIDENCE. Only repair: write a replacement attempt that uses the front-right workspace; do not slow a drill yet.
B · evidence story
Both conditions match. E and F: first mismatch = destination positions missed.
Draft: “Both miss destinations because of a bad hold; slow planning.”
First failure: “bad hold” was not observed. Only repair: remove that cause.
Because Fresh E and F both first miss destination positions, slow the named-U-setup planning drill.
C · doubled action
Both conditions match. E and F: first mismatch = edge-centre check fails.
Draft: “Because both fail edge-centre, slow recognition and switch to the left trigger.”
First failure: two actions; the trigger switch is unsupported. Only repair: retain the single matched action: slow recognition.

Quiz 1: classify before you repair

Fresh E/F match on pair, workspace, and checkpoint. In E the retained cue is said before setup; in F it is said after setup. Both logs report an edge-centre failure. What is the correct result?

Quiz 2: select the smallest repair

All four fields match. Both logs literally say “first mismatch = edge-centre check fails.” Draft: “Because both fail edge-centre due to rushing, slow the recognition drill.” Which edit is allowed?

2-minute cube-side triage

  1. Put three current Fresh E/F verdicts in separate rows.
  2. For each row, ask only: do all four condition fields match? Mark FRESH EVIDENCE and write one replacement plan if not.
  3. For every condition pass, underline the literal first mismatch. Cross out the first invented cause or extra action; leave all other clauses alone.
  4. Only rows that now pass condition → evidence → one action are ACT.

Ask your teacher to review a row if you cannot distinguish an observation from an explanation of why it happened.
